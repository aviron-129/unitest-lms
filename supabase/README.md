# Supabase: подключение UniTest

Проект: `https://mpiyzstuyddlupchwsjz.supabase.co`

## Один обязательный шаг

Publishable key не умеет создавать таблицы. Поэтому:

1. Открой Supabase → **SQL Editor** → **New query**.
2. Вставь содержимое `supabase/schema.sql`.
3. Нажми **Run**.
4. Убедись, что последний `select * from public.app_state limit 5;` выполнился без ошибки.

После этого приложение сможет читать и писать общие данные.

## Что это даёт

- `app_state` хранит все ключи приложения (`unitest*`) в JSONB.
- Студент, преподаватель и админ на разных устройствах видят одни и те же тесты, результаты, группы, объявления и чат.
- Локальный `localStorage` остаётся кэшем: если интернет пропал, приложение продолжает работать, а записи повторяются при восстановлении связи.

## Ограничения первого этапа

- Вход пока демо-ролевой (`student/teacher/manager/admin`), без Supabase Auth.
- Политики RLS временно разрешают чтение/запись всем с publishable key.
- Для реального вуза нужен второй этап: Auth, профили, RLS по ролям и отдельные таблицы.
- Последняя запись побеждает (last-write-wins); конфликты одновременного редактирования не разрешаются.

## Проверка

Открой приложение, войди, создай тест/объявление, обнови страницу на другом устройстве — данные должны появиться.
