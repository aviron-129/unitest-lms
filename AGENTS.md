# UniTest — инструкции для агента

## Что это
LMS-платформа университета: роли `admin`, `manager`, `teacher`, `student`.
Весь код приложения — **один файл `index.html`** (HTML + CSS + JS, без фреймворков).
Данные — mock + `localStorage`. Языки: `ru`, `uz`, `en`. Темы: light/dark.

## Перед любой задачей прочитай
1. Файл задачи из `Промты/Промт-NN-*.md` (в ночном режиме путь указан в prompt).
2. `Не-забыть.md` — расхождения промтов с реальным кодом.
3. `ПЛАН-ДЕЙСТВИЙ.md` — очередь и Definition of Done.
4. `progress.md` — что уже сделано.

## Железные правила
- Выполняй **ровно одну задачу** за сессию. Не начинай следующую.
- Не переписывай `index.html` целиком — только точечные правки.
- Не удаляй и не ломай существующий рабочий код других панелей.
- Новый текст — **во все 3 языка** (`translations.ru/uz/en`), без хардкода русских строк в UI.
- Новые блоки — в светлой и тёмной теме, на 375 / 768 / 1440 px.
- Пользовательский текст вставляй через `escapeHtml()`.
- Имена и данные сверяй с кодом: `activeTest` (не `currentTest`), `goToQuestion()` (не `nextQuestion`), группа `101-PR` (латиница), направления — ключи `programming`/`design`, а не русские строки.
- Слои: контент < `.app-header` (120) < моб. overlay (150) < моб. sidebar (200) < тест/результат (500) < модалки выше.
- Не подключай внешние библиотеки без необходимости. Уже есть KaTeX + mhchem, MathLive (`vendor/`), FontAwesome.
- Не делай `git commit`, `git push`, `git reset` — это работа ночного раннера.

## Проверка (обязательно после правок)
```powershell
node tests/run-all.js
node tests/verify-screens.js --task <id>
```
`run-all.js` — синтаксис, 8 функциональных наборов, статика/i18n, smoke.
`verify-screens.js` — реальный headless Chrome: скриншоты 1440/390, light/dark, ru/uz/en,
проверка заглушек, переполнения, console.error и ожидаемых селекторов.

Если проверка красная — исправляй, пока не станет зелёной. Не сдавай задачу с красными проверками.

## Документация
После успешной задачи обнови:
- `progress.md` — галочка и краткая запись;
- `План-этапов.md` — статус ✅;
- `Промты/00_ИНДЕКС.md` — статус ✅.

## Если задача невыполнима или требует решения
Не задавай вопросов (ночной режим). Выбери минимальный безопасный вариант,
запиши решение и причину в `night-blockers.md`, затем заверши сессию.
Не оставляй после себя сломанный `index.html`.

## Ночной режим (важно)
- Раннер сам делает коммит, а при красных проверках — WIP-ветку и откат к checkpoint.
  Не пытайся «спасти» git вручную.
- Одна сессия = одна задача. После очереди включается режим аудита: найди **одну**
  реальную проблему по указанному фокусу или ответь `AUDIT CLEAN`, если всё чисто.
- Если проверки красные — исправляй в рамках своей задачи; если не выходит,
  заверши сессию, раннер откатит изменения и пойдёт дальше.
