# UniTest — LMS-платформа университета

Демо-версия учебной платформы: тесты, расписание, зачётка, объявления, чат,
апелляции, панели преподавателя, менеджера и администратора.

Всё приложение — **один файл `index.html`** (HTML + CSS + JavaScript, без фреймворков
и без сборки). Данные хранятся в `localStorage` браузера.

## Как запустить

1. Откройте папку проекта.
2. Дважды щёлкните **`index.html`** (или перетащите файл в окно Chrome/Edge).
3. Войдите через единую форму: логин и пароль определяют роль (демо-аккаунты ниже).

Никакой сервер, npm и интернет не обязательны. Формулы работают офлайн:
MathLive лежит в `vendor/mathlive/`, KaTeX подключён с CDN (при отсутствии сети
формулы показываются как текст).

> Для проверки через локальный сервер тоже подойдёт любой статический сервер,
> но основной сценарий сдачи — открытие `index.html` по `file://`.

## Тестовые аккаунты

На экране входа — одна форма для всех ролей. Логин и пароль совпадают
(например, `student` / `student`); также подойдёт пароль `demo`.

| Роль | Логин | Пароль | Что видно |
|------|-------|--------|-----------|
| **Студент** | `student` | `student` | профиль, доступные тесты, расписание, объявления, чат, зачётка, апелляции |
| **Преподаватель** | `teacher` | `teacher` | дашборд, мои группы, создание тестов, результаты, расписание, объявления, апелляции, чат |
| **Менеджер** | `manager` | `manager` | дашборд направления, преподаватели, группы, студенты, тесты, отчёты, расписание |
| **Администратор** | `admin` | `admin` | дашборд вуза, факультеты, курсы, группы, пользователи, менеджеры, отчёты, настройки и журнал |

## Языки и темы

- Языки: **русский / узбекский / английский** (переключатель в шапке).
- Темы: **светлая / тёмная** (кнопка с солнцем/луной).
- Выбор сохраняется в `localStorage` (`unitest_lang`, `unitest_theme`).

## Сброс базы данных

1. Войдите как **Администратор**.
2. Откройте **Настройки**.
3. В «Опасной зоне» нажмите **«Сбросить базу данных»** и подтвердите.

Удаляются тесты, пользователи, группы, результаты, настройки и журнал.
Язык и тема сохраняются. При следующем открытии с пустым `localStorage`
демо-данные создаются заново (`initDefaultData()`).

Резервная копия: там же кнопка **«Скачать резервную копию»** — сохраняет JSON
со всеми ключами `unitest*`.

## Возможности

- 4 роли, разграничение данных по роли и направлению.
- Прохождение тестов: таймер, автосохранение, разбор ответов, оценки.
- Конструктор тестов: MathLive/KaTeX, матрицы, химия, схемы и графики.
- Расписание, объявления, зачётка, бейджи, апелляции, групповой чат.
- Админка: группы, пользователи, менеджеры, глобальные отчёты, журнал действий.
- Пустые состояния и обработка ошибок (битый `localStorage`, `QuotaExceededError`).

## Отладка

В начале скрипта: `const DEBUG = false;`. Отладочные сообщения идут через `dbg()`
и в финальной сборке (`file://`) не выводятся. `console.warn` и `console.error`
остаются для критических ошибок. В jsdom-тестах (`https://unitest.local`) логи
включены, чтобы проверять сообщения самопроверки.

## Проверки

```powershell
node tests/run-all.js
node tests/verify-screens.js --task 40
```

- `run-all.js` — синтаксис, функциональные jsdom-наборы, статика/i18n, smoke.
- `verify-screens.js` — headless Chrome: скриншоты 1440/390, light/dark, ru/uz/en,
  проверка заглушек, переполнения, `console.error` и селекторов.

Скриншоты проверок складываются в `screenshots/task<id>/`.

## Ограничения демо

- Нет сервера и настоящей авторизации: единая демо-форма входа, логин определяет роль,
  пароль демонстрационный.
- Данные живут только в текущем браузере (`localStorage`, ~5 МБ).
- Чат синхронизируется между вкладками через событие `storage`, но не между устройствами.
- Экспорт файлов и часть действий менеджера помечены как демо-режим.
