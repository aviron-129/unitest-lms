## 🌙 НОЧНОЙ РЕЖИМ (автономная работа)

1. Дважды кликнуть **`ЗАПУСТИТЬ-НОЧЬ.cmd`** (или `powershell -File .\night-run.ps1`).
2. Раннер берёт **одну** задачу из `night-tasks.json` (очередь №22–44), запускает отдельную сессию
   `opencode run --auto --agent night`, затем сам проверяет: `node tests/run-all.js` +
   `node tests/verify-screens.js --task <id>`.
3. Скриншоты — `screenshots/task<id>/`, отчёт — `НОЧНОЙ-ОТЧЁТ.md`, логи — `logs/`.
4. Красная проверка → WIP-ветка `wip/<id>/<время>` + откат к checkpoint, ночь **продолжается**.
   Watchdog перезапускает раннер после сбоя. Если процесс убили — при следующем запуске
   прерванная задача сохраняется в `wip/<id>/interrupted-*` и повторяется с чистого checkpoint.
   После очереди — режим аудита до конца сессии.
5. Утром: отчёт, скриншоты, `git log --oneline -10`, `git branch --list "wip/*"`.
6. Мягкая остановка: создать файл `night.stop`.

Настройки (модель, лимит задач/часов, таймаут, `stopOnFailure`) — в начале `night-tasks.json`.

## ⚠️ ПРАВИЛА, КОТОРЫЕ ЭКОНЯТ ЧАСЫ

1. **Один промт = одна задача.** Не пытайся объединить 3 в 1 — на 15-м шаге всё сломается.
2. **Правило трёх попыток.** Не получается с первого раза → попроси исправить, указав конкретную ошибку из консоли браузера (F12). Три неудачи подряд → переходи к следующему промту или разбей задачу мельче.
3. **Один промт = один этап.** Если AI потерял контекст — вставь заново Паспорт + последний рабочий код `index.html`.
4. **Проверяй в браузере после каждого промта** (F12 → Console). Без этого на 20-м шаге потеряешься.
5. **Дешёвой модели не давай архитектуру, дорогой — рутину.**
