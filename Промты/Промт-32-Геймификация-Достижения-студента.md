ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель студента. В разделе "Профиль" отрисовывается карточка с данными и статистикой (функция renderStudentProfile()).
- Результаты пройденных тестов хранятся в localStorage под ключом unitest_results (массив объектов с полями grade, testId, percent).

ЗАДАЧА №32 — Геймификация: Достижения (Бейджи) студента

ЧТО ДОЛЖНО БЫТЬ
1. Блок «Достижения» в профиле студента:
   - Под карточкой статистики (Доступно тестов / Пройдено / Средний балл) добавь новый блок "Мои достижения".
   - Внутри — сетка (Grid) из карточек-бейджей (например, 4 штуки).

2. Визуализация бейджей:
   - Полученный бейдж: Яркая цветная карточка с иконкой (FontAwesome), названием и коротким описанием.
   - Заблокированный бейдж: Та же карточка, но с opacity: 0.4 (полупрозрачная) и иконкой замка (🔒) вместо основной иконки, либо серым цветом. Текст описания должен подсказывать, как его получить.

3. Логика выдачи (КРИТИЧЕСКИ ВАЖНО):
   - Создай массив mockBadges с правилами:
     • id: 'first_test', условие: пройден хотя бы 1 тест.
     • id: 'excellent', условие: есть хотя бы одна оценка 5.
     • id: 'active', условие: пройдено 3 и более тестов.
     • id: 'perfect', условие: есть тест, сданный на 100% (percent === 100).
   - Функция checkBadges(results) должна проходить по массиву mockBadges и проверять условия на основе массива результатов из localStorage. Возвращать объект с флагом isUnlocked для каждого бейджа.
   - Функция renderBadges(results) должна отрисовывать эти карточки.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции checkBadges() добавь логи:
   - Для каждого бейджа выведи: console.log("Бейдж", badge.id, "разблокирован?", isUnlocked)
2. Если localStorage пуст (студент ничего не сдавал), все бейджи должны быть заблокированы. Выведи лог: console.log("У студента пока нет достижений")
3. Обязательно добавь бейджи в вызов renderStudentProfile(). Если бейджи не помещаются в один ряд, они должны переноситься (flex-wrap или grid).
4. Убедись, что если оценка 5 (бейдж 'excellent' открыт), но тестов пройдено меньше 3 (бейдж 'active' закрыт), визуально это отображается корректно (один цветной, другой серый).

ОГРАНИЧЕНИЯ
- Не делай звуковых эффектов или сложной анимации (только CSS transition для hover).
- Не добавляй новые страницы (всё в рамках профиля).
- Добавь переводы для новых текстов ("Мои достижения", "Первый шаг", "Отличник", "Активист", "Максимальный балл", а также подсказки "Пройдите 1 тест", "Получите оценку 5" и т.д.) на 3 языка.

АДАПТИВНОСТЬ
- Десктоп: 4 бейджа в один ряд (Grid 4 колонки).
- Планшет: 2 колонки.
- Мобильный: 2 колонки (чтобы не было слишком мелко) или 1 колонка.
