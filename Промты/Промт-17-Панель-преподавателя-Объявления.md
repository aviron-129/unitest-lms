ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель преподавателя: Дашборд, Мои группы, Создание теста, Мои тесты, Результаты, Расписание.
- Есть объект mockTeacher (id: 't1', name: 'Смирнов А.А.').
- Есть массив mockTeacherGroups (группы 101-ПР и 201-ПР).
- В промте №9 (панель студента) мы создали массив mockAnnouncements и функцию renderAnnouncements() для студента.
- В Sidebar преподавателя есть пункт "Объявления".

ЗАДАЧА №17 — Панель преподавателя: Объявления

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Объявления" в меню преподавателя вызывается renderTeacherAnnouncements().
   - Сверху должна быть кнопка "➕ Создать объявление".
   - Под кнопкой — список объявлений, созданных ЭТИМ преподавателем.

2. Форма создания (Модальное окно или выезжающая панель):
   - При клике на "Создать объявление" открывается форма.
   - Поле "Заголовок" (input type="text").
   - Поле "Текст объявления" (textarea).
   - Выпадающий список "Для группы" (select). Заполняется ТОЛЬКО группами этого преподавателя (101-ПР, 201-ПР). Можно добавить опцию "Для всех моих групп".
   - Кнопка "Опубликовать".

3. Сохранение и интеграция:
   - При нажатии "Опубликовать" создается объект объявления: { id: Date.now(), author: mockTeacher.name, role: 'Преподаватель', date: 'текущая_дата', title, text, targetGroup }.
   - Объект добавляется в глобальный массив mockAnnouncements.
   - Обновленный массив сохраняется в localStorage под ключом unitest_announcements.
   - После сохранения форма закрывается, список перерисовывается.
   - ВАЖНО: Студент (из Промта №9) должен видеть только те объявления, где targetGroup совпадает с его группой (или если targetGroup === 'all').

ДАННЫЕ
- Перепиши логику получения объявлений в renderAnnouncements() у студента и renderTeacherAnnouncements() у преподавателя: они должны сначала смотреть в localStorage.getItem('unitest_announcements'). Если там пусто — брать из изначального mockAnnouncements.

4. ГЛАВНАЯ ПРОВЕРКА: Зайди под студентом 101-ПР и убедись, что он видит новое объявление. Зайди под студентом 201-ПР (если есть) и убедись, что если объявление было для 101-ПР, то второй студент его НЕ видит.
