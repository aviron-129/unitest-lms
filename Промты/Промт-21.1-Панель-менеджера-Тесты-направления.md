ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель менеджера: Дашборд, Группы, Преподаватели, Студенты.
- Есть объект mockManager (direction: 'Программирование').
- Есть массив mockTeacherGroups (связь препода с группами и направлениями).
- Есть массив mockAllTeachers (все преподаватели).
- Есть массив mockTests (все созданные тесты, у каждого есть поле author - имя преподавателя).
- В Sidebar менеджера есть пункт "Тесты".

ЗАДАЧА №21.1 — Панель менеджера: Тесты направления

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Тесты" в меню менеджера вызывается функция renderManagerTests().

2. Список тестов:
   - Выводятся карточки тестов, созданных преподавателями ЭТОГО направления.
   - Карточка теста содержит:
     • Название теста (например, "Математика. Контрольная №3").
     • Автор (ФИО преподавателя).
     • Для каких групп назначен (например, "101-ПР").
     • Количество вопросов.
     • Статус (бейдж "Активен").
   - Кнопка "Посмотреть результаты" (при клике просто alert("Детальные результаты в разработке")).

3. Фильтр (Сверху):
   - Выпадающий список "Все преподаватели" (заполняется только преподавателями этого направления). При выборе преподавателя список тестов фильтруется.

ДАННЫЕ И ЛОГИКА (КРИТИЧЕСКИ ВАЖНО)
1. Шаг 1: Найди преподавателей направления (как в Промте 19).

   - const myTeachers = mockAllTeachers.filter(t => myTeacherIds.includes(t.id));
   - const myTeacherNames = myTeachers.map(t => t.name); (массив имен, например ['Смирнов А.А.'])
2. Шаг 2: Отфильтруй тесты.
   - Оставь только те тесты из mockTests, у которых поле author есть в массиве myTeacherNames.
3. Если тестов нет, выведи заглушку: "Преподаватели вашего направления еще не создали тестов".
