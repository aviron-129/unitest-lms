ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Цвета ролей: админ — фиолетовый, менеджер — синий, преподаватель — зеленый, студент — оранжевый.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Полностью готова панель студента (Профиль, Тесты, Расписание, Объявления, Зачётка).
- Готов Layout (Sidebar + Main).
- При выборе роли 'teacher' открывается панель преподавателя (пока с пустыми экранами).

ЗАДАЧА №11 — Панель преподавателя: Дашборд и Мои группы

ЧТО ДОЛЖНО БЫТЬ
1. Данные преподавателя (Mock):
   - Создай объект mockTeacher: { id: 't1', name: 'Смирнов А.А.', subject: 'Математика' }.

2. Дашборд преподавателя (Главный экран):
   - При выборе роли 'teacher' и пункта меню 'Дашборд' (или по умолчанию) вызывается renderTeacherDashboard().
   - Выведи приветствие: "Добро пожаловать, [Имя]".
   - Сделай 3 карточки статистики (Glassmorphism): 
     • "Мои группы": [число]
     • "Всего студентов": [число]
     • "Активные тесты": [число] (пока поставь 0 или 2).

3. Раздел "Мои группы":
   - При выборе пункта меню 'Мои группы' вызывается renderTeacherGroups().
   - Выведи карточки групп. Карточка должна содержать:
     • Название группы (например, 101-ПР).
     • Курс и Направление (например, 1 курс • Программирование).
     • Форма обучения (Очно).
     • Количество студентов (например, 24 студента).
     • Кнопка "Посмотреть студентов" (пока просто alert: "Список студентов будет в след. обновлении").
