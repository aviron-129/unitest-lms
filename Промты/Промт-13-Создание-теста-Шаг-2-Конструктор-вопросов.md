ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ

- currentTestDraft имеет вид: { title, subject, course, groups, form, questionsCount, timeLimit, access }.
- Сейчас при нажатии на кнопку "Далее" выводится alert. Нужно это изменить.

ЗАДАЧА №13 — Создание теста. Шаг 2: Конструктор вопросов

ЧТО ДОЛЖНО БЫТЬ
1. Переход к шагу 2:
   - Вместо alert в функции перехода к следующему шагу, теперь должна вызываться функция renderQuestionBuilder().
   - Она отрисовывает новый экран в Main Content (скрывая форму настроек).

2. Форма добавления нового вопроса (Карточка):
   - Заголовок: "Добавление вопроса (Добавлено: X из Y)".
   - Поле "Текст вопроса" (textarea).
   - 4 поля для вариантов ответа (input type="text").
   - Рядом с каждым вариантом — input type="radio" (чтобы отметить правильный ответ).
   - Кнопка "Добавить вопрос" (сохраняет вопрос в массив currentTestDraft.questions).

3. Список добавленных вопросов (Предпросмотр):
   - Под формой выводится список уже добавленных вопросов.
   - В каждом пункте: Текст вопроса, варианты ответов, правильный ответ подсвечен зеленым.
   - Кнопка "Удалить" (🗑️) рядом с вопросом (удаляет его из currentTestDraft.questions и перерисовывает список).

4. Кнопки навигации (внизу экрана):
   - "Назад к настройкам" (возвращает на Шаг 1).
   - "Завершить создание" (пока просто выводит alert("Черновик теста готов. Сохранение в базу будет в след. промте")).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции добавления вопроса (addQuestionToDraft()) обязательно добавь проверки:
   - Если текст вопроса пустой -> alert("Введите текст вопроса") и return.
   - Если хотя бы одно из 4 полей вариантов пустое -> alert("Заполните все 4 варианта ответов") и return.
   - Если не выбран правильный вариант (ни одна радио-кнопка) -> alert("Отметьте правильный вариант ответа") и return.
2. При успешном добавлении выведи в консоль:
   - console.log("Вопрос добавлен. Всего вопросов:", currentTestDraft.questions.length)
   - console.log("Текущий черновик:", currentTestDraft)
3. Убедись, что при удалении вопроса массив обновляется, и счетчик "Добавлено: X из Y" пересчитывается.
4. Если количество добавленных вопросов (currentTestDraft.questions.length) достигает значения currentTestDraft.questionsCount, покажи зеленое уведомление "Все вопросы добавлены!".

- Не добавляй другие типы вопросов (только "Один правильный ответ из 4-х").
- Не трогай другие экраны.
- Добавь переводы для новых текстов ("Добавление вопроса", "Текст вопроса", "Варианты ответов", "Правильный", "Добавить вопрос", "Удалить", "Назад к настройкам", "Завершить создание") на 3 языка.
