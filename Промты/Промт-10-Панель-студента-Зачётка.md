ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель студента (Профиль, Доступные тесты, Расписание, Объявления).
- Результаты пройденных тестов сохраняются в localStorage под ключом unitest_results (массив объектов: { testId, testTitle, score, percent, grade, date, answers }).
- В Sidebar есть пункт меню "Зачётка".

ЗАДАЧА №10 — Панель студента: Зачётка (Транскрипт)

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - Если текущая роль == 'student' и выбран пункт меню 'Зачётка', вызывается функция renderStudentTranscript().

2. Шапка (Статистика):
   - Блок с карточками: "Сдано дисциплин" (количество) и "Средний балл" (вычисляется динамически).

3. Таблица оценок (на десктопе):
   - Колонки: Предмет, Преподаватель, Дата, Оценка.
   - Оценка должна быть в виде красивого цветного бейджа (5 — зеленый, 4 — синий, 3 — оранжевый, 2 — красный).
   - Строки таблицы должны иметь hover-эффект (подсветку при наведении).

4. Список оценок (на мобильном):
   - Таблица скрывается, вместо нее выводятся карточки. В каждой карточке: Предмет, Дата, Оценка (бейдж), Преподаватель (мелким шрифтом).

5. Кнопка экспорта:
   - Справа над таблицей кнопка "📥 Скачать PDF" (при клике просто выводит alert("Экспорт в PDF в разработке")).

ДАННЫЕ
- Глобальный массив mockGrades (фиктивные оценки за экзамены, чтобы зачетка выглядела полной):
  [{ subject: 'История', teacher: 'Петров П.П.', date: '15.01.2026', grade: 4 }, { subject: 'Философия', teacher: 'Сидорова А.А.', date: '20.01.2026', grade: 5 }]
- В функции renderStudentTranscript():
  1. Возьми данные из localStorage.getItem('unitest_results'). Преобразуй их в формат mockGrades (взять testTitle, добавить фиктивное имя препода, взять date и grade).
  2. Объедини (concat) с массивом mockGrades.
  3. Итоговый массив назови allGrades.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. Вычисли средний балл. Для этого:
   - Если allGrades пуст, средний балл = 0.
   - Иначе: сумма всех grade поделенная на allGrades.length. Округли до 2 знаков (например, 4.33).
   - Добавь лог: console.log("Всего оценок:", allGrades.length, "Средний балл:", averageGrade)
2. Если allGrades пуст, отрисуй заглушку: "У вас пока нет оценок. Пройдите первый тест!".
3. Проверка верстки: Убедись, что если предметов много, таблица не ломает верстку, а корректно скроллится или переносит текст.

ОГРАНИЧЕНИЯ
- Не трогай другие экраны (Профиль, Тесты, Расписание).
- Не пиши реальную логику генерации PDF (только alert).
- Добавь переводы для новых текстов ("Зачётка", "Сдано дисциплин", "Средний балл", "Скачать PDF", "У вас пока нет оценок") на 3 языка.
