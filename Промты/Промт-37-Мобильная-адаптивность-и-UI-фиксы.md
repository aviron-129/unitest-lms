ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Полностью готовы все панели и функционал (включая чат, апелляции, бейджи, переводы).
- В некоторых разделах (Пользователи, Результаты, Отчёты) используются HTML-таблицы <table>.
- В шапке есть выпадающие меню (уведомления, поиск).
- В layout есть боковое меню (Sidebar), которое на мобильных должно скрываться.

ЗАДАЧА №37 — Мобильная адаптивность и UI-фиксы

ЧТО ДОЛЖНО БЫТЬ
1. Исправление горизонтального скролла (КРИТИЧЕСКИ ВАЖНО):
   - Убедись, что для body и основного контейнера задано overflow-x: hidden;. Широкие таблицы или элементы не должны ломать экран на мобильном.
   - Для таблиц на десктопе добавь обертку <div class="table-responsive"> со свойством overflow-x: auto;, чтобы они скроллились внутри себя, а не растягивали страницу.

2. Мобильные таблицы (Карточки):
   - В коде, где рендерятся таблицы (Пользователи, Результаты, Отчёты), убедись, что при ширине экрана < 768px:
     • Сама таблица <table> скрывается (display: none;).
     • Вместо неё отображается блок с карточками (display: flex; flex-direction: column; gap: 12px;), который мы делали в предыдущих промтах. Убедись, что эти карточки корректно отображают все данные (ФИО, Группа, Оценка и т.д.).

3. Sidebar (Боковое меню) на мобильных:
   - При ширине < 768px Sidebar должен быть скрыт за левым краем экрана (transform: translateX(-100%); position: fixed; z-index: 1000;).
   - При нажатии на бургер-меню (или иконку) он должен выезжать (transform: translateX(0);).
   - Обязательно добавь полупрозрачный темный фон (overlay) поверх контента, когда меню открыто. При клике на этот фон меню должно закрываться.

4. Выпадающие меню в шапке (Уведомления, Поиск):
   - На мобильных устройствах они не должны вылезать за пределы экрана.
   - Задай им position: absolute; right: 10px; left: 10px; width: auto; (чтобы растягивались по ширине с отступами).

5. Модальные окна:
   - Убедись, что любое модальное окно (создание пользователя, группы, апелляции) на мобильном имеет max-height: 90vh; overflow-y: auto;, чтобы кнопки "Сохранить" и "Отмена" не уходили за нижний край экрана.
