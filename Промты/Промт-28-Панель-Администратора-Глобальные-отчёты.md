ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель Админа: Дашборд, Группы, Пользователи, Менеджеры.
- Есть массив mockTeacherGroups (содержит поля name, course, direction).
- Есть массив mockAllStudents.
- Результаты тестов хранятся в localStorage под ключом unitest_results (объекты с полями grade, studentGroup, testId).
- В Sidebar админа есть пункт "Отчёты".

ЗАДАЧА №28 — Панель Администратора: Глобальные отчёты

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Отчёты" вызывается функция renderAdminReports().

2. Панель фильтров (Сверху):
   - Выпадающий список "Курс" (Все, 1, 2, 3, 4, 5).
   - Выпадающий список "Направление" (Все + уникальные из mockTeacherGroups).
   - Кнопка "📥 Экспорт в Excel" (при клике alert("Экспорт в Excel в разработке")).

3. Карточки общей статистики:
   - "Всего сдано тестов" (количество результатов, подходящих под фильтр).
   - "Средний балл по вузу" (среднее арифметическое всех оценок, округленное до 2 знаков, например 4.25).

4. Таблица успеваемости групп:
   - Колонки: Группа, Курс, Направление, Кол-во студентов, Средний балл, Успеваемость (визуальный прогресс-бар).
   - Прогресс-бар: ширина полоски зависит от среднего балла (например, если средний балл 4.5 из 5, то ширина = 90%). Цвет полоски: >4.5 — зеленый, >3.5 — синий, остальное — оранжевый.

ЛОГИКА И САМОПРОВЕРКА (КРИТИЧЕСКИ ВАЖНО)
1. При отрисовке функции renderAdminReports() собери все результаты из localStorage (или из mockHistoricalResults, если localStorage пуст).
2. Фильтрация:
   - При смене фильтров (Курс или Направление) таблица и карточки должны пересчитываться.
   - Отфильтруй группы из mockTeacherGroups по выбранному курсу и направлению.
   - Оставь только те результаты, у которых studentGroup совпадает с названиями этих отфильтрованных групп.
3. Подсчет среднего балла:
   - Для каждой группы: найди все результаты этой группы и посчитай среднее. 
   - Если результатов нет, средний балл = 0, прогресс-бар серый.
4. ДОБАВЬ ЛОГИ В КОД:
   - При применении фильтров: console.log("Применены фильтры. Курс:", selectedCourse, "Направление:", selectedDirection)
   - При подсчете глобального среднего балла: console.log("Общий средний балл по вузу:", globalAvg)
   - Для каждой группы: console.log("Группа:", group.name, "Средний балл:", avgGrade, "Результатов:", resultsCount)

ОГРАНИЧЕНИЯ
- Не используй внешние библиотеки для графиков (Chart.js и т.д.). Только CSS (div с шириной в процентах).
- Не трогай другие панели.
- Добавь переводы для новых текстов ("Отчёты", "Все курсы", "Все направления", "Всего сдано тестов", "Средний балл по вузу", "Успеваемость", "Нет данных") на 3 языка.
