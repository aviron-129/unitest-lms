ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Проект содержит ~3000 строк кода. У нас есть глобальный объект translations (в начале скрипта) и переменная currentLang.
- За время разработки мы добавили много новых кнопок, заголовков, модальных окон и alert-сообщений. Многие из них написаны на русском языке напрямую (hardcoded).
- Переключатель языков в шапке работает, но переводит только те элементы, которые были добавлены в самом начале.

ЗАДАЧА №36 — Аудит и полная локализация интерфейса

ЧТО ДОЛЖНО БЫТЬ (ПОШАГОВО)
1. Расширение словаря:
   - Проверь объект translations. Убедись, что в нем есть ключи для ВСЕХ надписей на 3 языках (uz, ru, en).
   - Сюда должны входить: пункты меню (Дашборд, Мои группы, Чат и т.д.), заголовки таблиц (ФИО, Группа, Оценка), тексты кнопок (Создать, Сохранить, Назад, Выйти, Отправить), и тексты всех alert (например, "Заполните поля", "Вы уверены?", "Тест сохранен").

2. Внедрение функции перевода:
   - Создай или обнови функцию t(key), которая возвращает перевод текущего языка: return translations[currentLang][key] || key;.
   - Замени ВСЕ жестко прописанные тексты в HTML-шаблонах (внутри JS-функций типа renderStudentProfile, renderTeacherDashboard и т.д.) на вызовы t('название_ключа'). 
   - Обрати внимание на placeholder в инпутах (например, "Поиск по ФИО").

3. Локализация динамических сообщений (Alerts):
   - Найди все alert("...") и confirm("...") в коде.
   - Замени русский текст на t('ключ_алерта'). 
   - Пример: было alert("Группа создана"), стало alert(t('group_created')).

4. Мгновенная смена языка:
   - Убедись, что при переключении языка (вызов changeLanguage(lang)) происходит не просто сохранение в localStorage, а принудительная перерисовка текущего активного экрана. 
   - Для этого в конце функции changeLanguage() вызови функцию роутера navigate(currentSection) или location.reload() (если перерисовка слишком сложна, но лучше без перезагрузки).
