ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель менеджера: Дашборд, Группы, Преподаватели, Студенты.
- Есть mockManager (direction: 'Программирование').
- Есть mockAllTeachers (преподаватели) и mockTeacherGroups (связь препода с направлением).
- Есть mockTests (тесты). У каждого теста есть поле author (имя преподавателя).
- В Sidebar менеджера есть пункты "Тесты" и "Отчёты".

ЗАДАЧА №21 — Панель менеджера: Тесты направления и Отчёты

ЧТО ДОЛЖНО БЫТЬ
1. Раздел "Тесты направления" (renderManagerTests()):
   - Выводятся карточки тестов, созданных преподавателями ЭТОГО направления.
   - Карточка теста: Название, Автор (преподаватель), Для каких групп, Кол-во вопросов, Статус.
   - Кнопка "Посмотреть результаты" (пока alert: "Детальные результаты в разработке").

2. Раздел "Отчёты" (renderManagerReports()):
   - Выводятся карточки успеваемости по группам направления.
   - В карточке группы (например, 101-ПР): 
     • Название группы.
     • Средний балл (вычисляется динамически).
     • Количество сданных тестов (из localStorage).
     • Визуальная шкала (progress bar) успеваемости.
