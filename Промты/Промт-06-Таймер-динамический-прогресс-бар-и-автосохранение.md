ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Есть экран прохождения теста (test-taking).
- Есть переменные: currentQuestionIndex, userAnswers, mockQuestions.
- Есть функция startTest(testId), которая запускает тест.
- Таймер пока просто текст "⏱ 45:00", прогресс-бар статичен.

ЗАДАЧА №6 — Таймер, динамический прогресс-бар и автосохранение

ЧТО ДОЛЖНО БЫТЬ
1. Реальный таймер (Обратный отсчет):
   - При вызове startTest(testId) должен запускаться таймер (функция startTimer(seconds)).
   - Таймер каждую секунду уменьшает время и обновляет текст в шапке (формат MM:SS).
   - Если время доходит до 00:00, таймер останавливается, и вызывается alert("Время вышло!"). (Реальный экран результатов будет в следующих промтах).
   - При завершении теста (кнопка "Завершить") таймер должен останавливаться (функция stopTimer()).

2. Динамический прогресс-бар:
   - Полоска прогресса в шапке должна визуально заполняться в зависимости от текущего вопроса.
   - Формула ширины: (currentQuestionIndex + 1) / totalQuestions * 100%.

3. Автосохранение (Критически важно):
   - Создай функцию saveProgress(), которая сохраняет в localStorage под ключом unitestactivetest объект:
     { testId: currentTest.id, answers: userAnswers, index: currentQuestionIndex, timeLeft: secondsLeft }.
   - Вызывай saveProgress() каждый раз, когда студент выбирает ответ (selectAnswer), переключает вопрос (nextQuestion, prevQuestion) и каждые 5 секунд работы таймера.
   - Создай функцию restoreProgress(testId). Если при запуске startTest(testId) в localStorage есть сохранение с таким же testId, нужно спросить пользователя через confirm("Найдено сохранение. Продолжить с места остановки?"). Если да — восстановить userAnswers, currentQuestionIndex и оставшееся время. Если нет — очистить сохранение и начать заново.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции saveProgress() добавь:
   - console.log("Прогресс сохранен в localStorage:", { testId: currentTest.id, timeLeft: secondsLeft })
2. В функции startTimer() внутри интервала (каждую секунду) добавь проверку, чтобы таймер не уходил в минус:
   - if (secondsLeft <= 0) { clearInterval(timerId); alert("Время вышло!"); }
3. После восстановления прогресса выведи:
   - console.log("Прогресс восстановлен. Ответы:", userAnswers)
4. Убедись, что при нажатии на "Завершить" (или выходе с экрана) сохранение либо удаляется, либо помечается как завершенное (для нашего проекта просто удаляй ключ unitestactivetest).

ОГРАНИЧЕНИЯ
- Не делай пока экран результатов и подсчет баллов.
- Не трогай другие экраны и панели (Профиль, Список тестов).
- Код должен быть прокомментирован.

АДАПТИВНОСТЬ
- На мобильном таймер и прогресс-бар могут быть в одну строку или компактно сверху, главное — чтобы они не перекрывали текст вопроса.
