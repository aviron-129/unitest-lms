ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Проект полностью функционален: есть 4 роли, тесты, чат, апелляции, локализация и обработка ошибок.
- В процессе разработки (40 промтов) в коде накопилось много console.log, которые нужны были для проверок, но теперь мешают.
- Есть глобальный таймер теста (setInterval), который может продолжать работать в фоне, если студент резко выйдет из теста.

ЗАДАЧА №40 — Финальная очистка и подготовка к сдаче

ЧТО ДОЛЖНО БЫТЬ
1. Очистка консоли (Console Cleanup):
   - Найди все console.log в проекте.
   - Создай глобальную переменную в начале скрипта: const DEBUG = false;.
   - Оберни отладочные логи в условие: if (DEBUG) console.log("Текст", data);.
   - Оставь без изменений только console.error и console.warn (они нужны для отслеживания критических ошибок).

2. Защита от утечек памяти (Таймеры):
   - Найди функцию запуска таймера в тесте (startTimer или setInterval).
   - Убедись, что функция clearInterval вызывается ВЕЗДЕ, где это необходимо:
     • При нажатии на кнопку "Завершить тест".
     • При выходе из теста (кнопка "Назад" в браузере или возврат к списку тестов).
     • При выходе из аккаунта (кнопка "Выйти" в Sidebar).
   - Если этого нет, добавь вызов clearInterval(timerId) в функцию роутера (navigate) при смене экрана.

3. Финальная проверка Mock-данных (Bootstrap):
   - Напиши функцию initDefaultData(), которая вызывается в самом начале (при initApp()).
   - Она должна проверять: если localStorage абсолютно пуст (пользователь зашел впервые), заполнить его базовыми тестами, пользователями и группами, чтобы приложение не выглядело "мертвым" при первом запуске.

4. Генерация файла README (Инструкция):
   - В ответе (вне блока с кодом) напиши текст для файла README.md.
   - В инструкции укажи: как запустить (просто открыть index.html), какие есть тестовые аккаунты (например, "Для входа под студентом выберите роль Студент"), и как сбросить базу (через панель Админа).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. Выведи в консоль финальный отчет о сборке:

2. Проверь, что при выходе из теста (кнопка "Выйти" в меню) таймер перестает тикать (в консоли не должно быть спама от setInterval).
3. Убедись, что при DEBUG = false в консоли чисто, и выводятся только console.error (если специально сломать JSON).
