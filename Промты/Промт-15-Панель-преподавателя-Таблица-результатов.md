ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Преподаватель может создавать тесты, они сохраняются в mockTests (и в localStorage).
- Студенты проходят тесты, результаты сохраняются в localStorage под ключом unitest_results (массив объектов: { testId, testTitle, score, percent, grade, date, studentName, studentGroup }). Примечание: в промте №7 мы не сохраняли имя студента, поэтому ИИ нужно будет брать его из mockStudent, если результат сохраняется сейчас.
- В Sidebar преподавателя есть пункт "Результаты" (или "Результаты студентов").
