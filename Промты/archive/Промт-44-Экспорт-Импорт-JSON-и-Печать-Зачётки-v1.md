ЗАДАЧА №44 — Экспорт/Импорт JSON и Печать Зачётки

ЧТО ДОЛЖНО БЫТЬ
1. Реальный экспорт JSON (Панель Админа):
   - Замени alert на функцию exportDatabase().
   - Функция должна собрать все ключи из localStorage (например, uniteststudents, unitesttests и т.д.) в один объект.
   - Преобразовать объект в JSON-строку.
   - Создать Blob, сгенерировать ссылку через URL.createObjectURL и программно кликнуть по ней, чтобы браузер скачал файл unitest_backup.json.

2. Реальный импорт JSON (Панель Админа):
   - Добавь кнопку "📤 Загрузить базу". При клике открывается скрытый <input type="file" accept=".json">.
   - При выборе файла прочитай его через FileReader, сделай JSON.parse и запиши все данные обратно в localStorage.
   - После успешной загрузки выведи alert("База успешно восстановлена!") и перезагрузи страницу (location.reload()).

3. Печать PDF (Зачётка студента):
   - В разделе "Зачётка" замени alert у кнопки "Скачать PDF" на вызов window.print().
   - ВАЖНО: Добавь в CSS блок @media print, который скрывает Sidebar, верхнюю шапку и все кнопки. В распечатку должна попасть ТОЛЬКО таблица с оценками и ФИО студента.
   - Добавь в @media print правило: body { background: white; color: black; }, чтобы при печати не тратился картридж на темный фон.

САМОПРОВЕРКА
1. Проверь, что при скачивании файла он имеет расширение .json.
2. Проверь, что после нажатия на печать зачётки в предпросмотре браузера видны только оценки.
