ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Цвета ролей: админ — фиолетовый, менеджер — синий, преподаватель — зеленый, студент — оранжевый.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готов файл index.html с роутером (navigate), Sidebar, Header.
- Готова роль 'student' и раздел 'Профиль' (карточка студента + статистика).
- Есть глобальный объект mockStudent (курс, направление, группа, форма, категория).
- Есть функция renderStudentProfile().

ЗАДАЧА №4 — Панель студента: Список доступных тестов

ЧТО ДОЛЖНО БЫТЬ
Если текущая роль == 'student' и выбран пункт меню 'Доступные тесты' (или 'Мои тесты'), в Main Content отрисовывается список карточек тестов.

1. Карточка теста (Glassmorphism):
   - Иконка предмета (например, калькулятор для математики).
   - Название теста (например, "Математика. Контрольная №3").
   - Имя преподавателя (например, "Смирнов А.А.").
   - Кол-во вопросов (например, "20 вопросов") и время ("45 мин").
   - Дедлайн (например, "до 15.10.2026").
   - Статус: если тест уже пройден (есть в localStorage) — зеленая плашка "✓ Пройдено". Если нет — кнопка "▶ Начать тест".
   - ПРИ КЛИКЕ на "Начать тест" пока просто выводи console.log("Запуск теста:", test.id) и alert("Переход к экрану прохождения теста (будет в след. промте)"). Реальный переход не делай.

2. Фильтрация (КРИТИЧЕСКИ ВАЖНО):
   - Создай массив mockTests с 4–5 тестами.
   - У каждого теста должны быть свойства: id, title, subject, teacher, questionsCount, timeLimit, deadline, targetCourse, targetDirection, targetGroup, targetForm.
   - Студент должен видеть ТОЛЬКО те тесты, где:
     test.targetCourse === mockStudent.course И
     test.targetDirection === mockStudent.direction И
     test.targetGroup === mockStudent.group (или группа входит в массив разрешенных).
   - Сделай 1-2 теста, которые НЕ подходят студенту (например, для 3 курса или другой группы), чтобы проверить, что они не отображаются.

ДАННЫЕ
- Массив mockTests (глобальная переменная).
- Прогресс прохождения: читай из localStorage.getItem('unitest_results'). Если там есть запись с testId, совпадающим с ID теста, показывай статус "Пройдено".
