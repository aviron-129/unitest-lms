ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готов файл index.html с Layout: Sidebar и Main Content.
- Есть роль 'student'. В меню есть пункт "Расписание".
- При клике на пункт меню меняется заголовок в Main.
- Есть глобальный объект mockStudent (курс, направление, группа).
- Есть функция navigate(sectionName), отвечающая за переключение разделов.

ЗАДАЧА №8 — Панель студента: Расписание

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - Если текущая роль == 'student' и выбран пункт меню 'Расписание', в Main Content должна вызываться функция renderStudentSchedule().

2. Сетка расписания (Визуал):
   - Заголовок "Расписание занятий".
   - Выведи дни недели (Понедельник — Суббота).
   - На десктопе: сетка (Grid) из 6 колонок (по дням).
   - В каждой колонке — карточки пар (если они есть). Если пар нет — серый текст "Нет занятий".
   - Карточка пары должна содержать:
     • Время (например, 09:00 - 10:30)
     • Название предмета (например, Математика)
     • Тип занятия (Лекция / Практика / Лабораторная)
     • Преподаватель (например, Смирнов А.А.)
     • Аудитория (например, ауд. 204)
   - Цвет карточки пары зависит от типа: Лекция (синий), Практика (зеленый), Лабораторная (оранжевый).

ДАННЫЕ

- ВАЖНО: Убедись, что в массиве есть пары как для группы mockStudent.group (например, '101-ПР'), так и для чужой группы (например, '201-ПР').
