ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готов Layout: Sidebar и Header. В Header есть иконка колокольчика (пока без логики) и красная точка.
- Есть роль 'student'. В меню есть пункт "Объявления".
- Есть функция navigate(sectionName).

ЗАДАЧА №9 — Панель студента: Уведомления и Объявления

ЧТО ДОЛЖНО БЫТЬ
1. Выпадающее меню уведомлений (Header):
   - При клике на иконку колокольчика должна открываться/закрываться панель (dropdown) с уведомлениями.
   - Панель позиционируется абсолютно (absolute), не сдвигая остальной контент.
   - Внутри: заголовок "Уведомления" и список (максимум 3 последних).
   - Если есть непрочитанные, точка на колокольчике горит. При клике на "Отметить все как прочитанные" (или при открытии) точка исчезает.
