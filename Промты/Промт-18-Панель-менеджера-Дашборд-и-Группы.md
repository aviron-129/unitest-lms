ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Цвета ролей: админ — фиолетовый, менеджер — синий, преподаватель — зеленый, студент — оранжевый.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Полностью готовы панели Студента и Преподавателя.
- Есть массив mockTeacherGroups, в котором лежат группы (101-ПР, 201-ПР, 102-ДЗ и т.д.). У каждой группы есть поле direction (например, 'Программирование').
- В Sidebar при выборе роли 'manager' есть пункты меню: Дашборд, Преподаватели, Группы, Студенты, Тесты, Отчёты, Расписание.

ЗАДАЧА №18 — Панель менеджера: Дашборд и Группы

ЧТО ДОЛЖНО БЫТЬ
1. Данные менеджера (Mock):
   - Создай объект mockManager: { id: 'm1', name: 'Петров П.П.', direction: 'Программирование' }.

2. Дашборд менеджера:
   - При выборе роли 'manager' и пункта меню 'Дашборд' вызывается renderManagerDashboard().
   - Выведи приветствие: "Добро пожаловать, [Имя]. Направление: [direction]".
