ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Есть главный экран со списком тестов студента (mockTests).
- При клике на "Начать тест" сейчас вызывается alert.
- Есть функция navigate(sectionName) для переключения экранов внутри панели.

ЗАДАЧА №5 — Экран прохождения теста (Вопросы и ответы)

ЧТО ДОЛЖНО БЫТЬ
1. Переход на экран:
   - При клике на "Начать тест" убери alert. Теперь этот клик должен вызывать новую функцию startTest(testId), которая скрывает список тестов и открывает экран прохождения (назовем его 'test-taking').

2. Шапка экрана теста (Header):
   - Слева: Название теста.
   - По центру: Прогресс-бар (заполненность зависит от текущего вопроса).
   - Справа: Таймер (пока просто визуальный текст "⏱ 45:00", реальный отсчет времени сделаем в следующем промте, чтобы не перегружать).
   - Надпись "Вопрос X из Y" (например, Вопрос 1 из 20).

3. Тело вопроса:
   - Текст вопроса (крупный шрифт).
   - 4 варианта ответа. Оформи их как крупные кликабельные карточки (не стандартные radio-кнопки, а красивые блоки).
   - При клике на вариант он подсвечивается акцентным цветом (выбран).
   - Выбранный вариант сохраняется в массив userAnswers по индексу вопроса.

4. Кнопки навигации (Footer):
   - Кнопка "Назад" (неактивна/скрыта на первом вопросе).
   - Кнопка "Далее" (неактивна/скрыта на последнем вопросе).
   - Кнопка "Завершить" (всегда видна, при клике пока выводит alert "Тест завершен (подсчет будет в след. промте)").

ДАННЫЕ
- Создай массив mockQuestions из 5 вопросов для первого теста. Структура:
  { id: 1, text: "Чему равно 2+2?", options: ["3", "4", "5", "22"], correct: 1 }
- Переменные состояния: currentQuestionIndex (начинается с 0), userAnswers (пустой массив).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции выбора ответа (selectAnswer(index)) обязательно добавь:
   - console.log("Выбран ответ:", index, "для вопроса:", currentQuestionIndex)
   - console.log("Текущий массив ответов:", userAnswers)
2. При нажатии "Далее" и "Назад" добавь:
   - console.log("Переход к вопросу с индексом:", currentQuestionIndex)
3. Убедись, что при переходе между вопросами выбранный ранее ответ (если он есть в userAnswers) отрисовывается как активный.

ОГРАНИЧЕНИЯ
- НЕ делай экран результатов (это будет в следующих промтах).
- НЕ делай реальный таймер (только текст).
- НЕ добавляй логику блокировки клавиш или выхода из fullscreen (прокторинг) — это отдельный сложный модуль.
- Не трогай другие экраны.
- Добавь переводы для новых текстов ("Вопрос", "Назад", "Далее", "Завершить") на 3 языка.

АДАПТИВНОСТЬ
- На мобильном: карточки ответов на всю ширину, кнопки навигации прижаты к низу экрана (sticky bottom), чтобы до них было удобно доставать большим пальцем.
- На десктопе: контент ограничен по ширине (например, max-width: 800px) и отцентрирован.
