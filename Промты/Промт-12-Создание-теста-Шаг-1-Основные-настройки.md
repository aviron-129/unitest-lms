ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Цвета ролей: админ — фиолетовый, менеджер — синий, преподаватель — зеленый, студент — оранжевый.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель преподавателя: Дашборд и Мои группы.
- Есть объект mockTeacher (id: 't1', name: 'Смирнов А.А.', subject: 'Математика').
- Есть массив mockTeacherGroups (группы 101-ПР и 201-ПР принадлежат 't1').
- В Sidebar есть пункт "Создать тест".

ЗАДАЧА №12 — Создание теста. Шаг 1: Основные настройки

ЧТО ДОЛЖНО БЫТЬ
При клике на "Создать тест" в Main Content должна отрисовываться форма renderCreateTestForm().
Форма разбита на логические блоки (карточки):

1. Блок "Основная информация":
   - Поле "Название теста" (input type="text", обязательное, placeholder: "Например: Контрольная работа №3").
   - Поле "Предмет" (input type="text", readonly, автоматически подставляется mockTeacher.subject).

2. Блок "Кому назначен тест" (КРИТИЧЕСКИ ВАЖНО):
   - Поле "Курс" (select). Доступны только те курсы, в которых у преподавателя есть группы. (Если у него 1 и 2 курс, то в списке только они. Курсы 3, 4, 5 заблокированы/скрыты).
   - Поле "Группы" (мультивыбор через чекбоксы). При выборе курса должны отображаться только группы этого курса и этого преподавателя (101-ПР или 201-ПР). Чужих групп быть не должно.
   - Поле "Форма обучения" (select: Очно / Заочно / Оба).

3. Блок "Параметры теста":
   - Поле "Количество вопросов" (input type="number", min="1").
   - Поле "Время на прохождение (минуты)" (input type="number", min="1").
   - Поле "Доступ" (select: Все студенты / Только лучники).

4. Кнопки управления:
   - Кнопка "Отмена" (возвращает на дашборд).
   - Кнопка "Далее: Добавить вопросы" (сохраняет текущие настройки в глобальную переменную currentTestDraft и выводит alert("Настройки сохранены. Переход к вопросам (будет в след. промте)")).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции renderCreateTestForm() при изменении значения в селекте "Курс", функция должна перерисовывать список чекбоксов групп.
2. Добавь лог: console.log("Выбран курс:", selectedCourse, "Доступные группы:", availableGroups)
3. Если пользователь нажимает "Далее" с пустым названием теста или не выбранной ни одной группой, выведи alert("Заполните все обязательные поля и выберите хотя бы одну группу!") и не переходи дальше.
4. Убедись, что в выпадающем списке курсов нет курсов, на которых у преподавателя нет групп.

ОГРАНИЧЕНИЯ

- НЕ записывай тест в localStorage (только в переменную currentTestDraft).
- Не трогай другие экраны.
- Добавь переводы для новых текстов на 3 языка.
