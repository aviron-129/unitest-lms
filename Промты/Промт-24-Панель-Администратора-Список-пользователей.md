ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель Админа: Дашборд.
- Есть массивы mockAllStudents (студенты), mockAllTeachers (преподаватели).
- Есть объект mockManager (менеджер Петров П.П.). В промте №23 мы не создавали массив менеджеров, только один объект.
- В Sidebar админа есть пункт "Пользователи".

ЗАДАЧА №24 — Панель Администратора: Список пользователей

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Пользователи" в меню админа вызывается renderAdminUsers().

2. Панель фильтров (Сверху):
   - Поле поиска (input type="text", placeholder: "Поиск по имени...").
   - Выпадающий список "Роль" (Все, Студент, Преподаватель, Менеджер).
   - Кнопка "➕ Добавить пользователя" (при клике alert: "Форма добавления в разработке").

3. Таблица пользователей (Десктоп):
   - Колонки: ФИО, Роль (цветной бейдж), Доп. информация, Статус (Активен).
   - В колонке "Доп. информация":
     • Если Студент -> выводи его группу (например, 101-ПР).
     • Если Преподаватель -> выводи его предмет (например, Математика).
     • Если Менеджер -> выводит его направление (например, Программирование).
   - Строки кликабельны (при клике alert: "Карточка пользователя в разработке").

4. Карточки пользователей (Мобильный):
   - Вместо таблицы — карточки с той же информацией.

ДАННЫЕ И ЛОГИКА (КРИТИЧЕСКИ ВАЖНО)
1. Создай массив mockAllManagers с одним менеджером: [ { id: 'm1', name: 'Петров П.П.', direction: 'Программирование' } ]. (Если хочешь, добавь второго).
2. Объединение массивов: Создай единый массив allUsers. Тебе нужно привести всех к единому формату:
   - Студенты: { id, name, role: 'Студент', extra: group }
   - Преподаватели: { id, name, role: 'Преподаватель', extra: subject }
   - Менеджеры: { id, name, role: 'Менеджер', extra: direction }
   - (Используй методы массивов: map, spread оператор [...arr1, ...arr2]).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции renderAdminUsers() выведи в консоль общее количество пользователей:
   - console.log("Всего пользователей в системе:", allUsers.length)
2. Напиши функцию filterUsers(), которая срабатывает при вводе в поиск и смене роли.
   - Она должна фильтровать массив allUsers по роли (если выбрана не "Все") и по имени (через .toLowerCase().includes()).
   - Вызывай ее при событиях input и change.
   - Добавь лог: console.log("Отфильтровано пользователей:", filteredUsers.length)
3. Если ничего не найдено, выведи заглушку: "Пользователи не найдены. Измените параметры поиска".
4. ПРОВЕРКА: Убедись, что бейджи ролей имеют разные цвета (например, студент — оранжевый, препод — зеленый, менеджер — синий).

ОГРАНИЧЕНИЯ

- Не трогай другие панели.
