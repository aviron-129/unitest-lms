ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель Админа: Дашборд и Пользователи.
- Есть массив mockTeacherGroups (в нём есть группы 101-ПР, 201-ПР с direction: 'Программирование' и 102-ДЗ с direction: 'Дизайн').
- В Sidebar админа есть пункт "Группы" (или "Факультеты/Группы").

ЗАДАЧА №25 — Панель Администратора: Управление группами

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Группы" вызывается функция renderAdminGroups().

2. Список групп (Аккордеон или группировка):
   - Выведи группы, сгруппированные по направлениям (например, сначала блок "Программирование", под ним карточки групп).
   - Карточка группы: Название (101-ПР), Курс (1 курс), Форма (Очно), Кол-во студентов (из mockAllStudents).
   - Кнопка "Редактировать" (пока просто alert).

3. Кнопка "➕ Создать группу":
   - Сверху над списком (при клике открывается модальное окно или выезжающая панель).

4. Форма создания группы (Модальное окно):
   - Поля:
     • Название группы (текст, например, "301-ПР").
     • Курс (число от 1 до 5).
     • Направление (выпадающий список). Заполняется уникальными значениями из mockTeacherGroups + хардкод ('Программирование', 'Дизайн', 'Экономика').
     • Форма обучения (Очно / Заочно).
   - Кнопки "Отмена" и "Сохранить".

5. Сохранение:
   - При нажатии "Сохранить" создается объект: { id: 'g_' + Date.now(), name, course, direction, form, studentsCount: 0, teacherId: null }.
   - Объект добавляется в массив mockTeacherGroups.
   - Обновленный массив сохраняется в localStorage (ключ unitest_groups).
   - Модальное окно закрывается, список групп перерисовывается.
