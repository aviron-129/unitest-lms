ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Проект полностью готов функционально (40 промтов завершены).
- У нас есть формы ввода (чат, создание тестов, объявления, апелляции) и ролевая модель (переменная currentRole).
- Данные выводятся на экран через шаблонные строки и innerHTML.
