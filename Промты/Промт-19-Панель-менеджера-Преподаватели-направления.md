ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель менеджера: Дашборд и раздел "Группы" (с фильтрацией по направлению менеджера).
- Есть объект mockManager (id: 'm1', name: 'Петров П.П.', direction: 'Программирование').
- Есть массив mockTeacherGroups, в котором у каждой группы есть teacherId (например, 't1').
- В Sidebar менеджера есть пункт "Преподаватели".

ЗАДАЧА №19 — Панель менеджера: Преподаватели направления

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Преподаватели" в меню менеджера вызывается функция renderManagerTeachers().

2. Список преподавателей:
   - Выводятся карточки преподавателей. В карточке:
     • Аватар (инициалы).
     • ФИО (например, Смирнов А.А.).
     • Предмет (например, Математика).
     • Список групп, которые он ведет в этом направлении (например, "Группы: 101-ПР, 201-ПР").
     • Кнопка "Назначить группу" (пока просто alert("Назначение групп в разработке")).
     • Кнопка "Редактировать" (тоже alert).

3. Кнопка "Добавить преподавателя":
   - Сверху над списком должна быть кнопка "➕ Добавить преподавателя" (при клике alert("Добавление преподавателя в разработке")).

ДАННЫЕ И ЛОГИКА (КРИТИЧЕСКИ ВАЖНО)
1. Создай массив mockAllTeachers:
   [ { id: 't1', name: 'Смирнов А.А.', subject: 'Математика' }, { id: 't2', name: 'Иванова Е.П.', subject: 'Русский язык' }, { id: 't3', name: 'Ким О.В.', subject: 'Физика' } ]
2. В твоем массиве mockTeacherGroups уже есть группы (101-ПР с teacherId: 't1', 201-ПР с teacherId: 't1', и 102-ДЗ (Дизайн) с teacherId: 't2').
3. ЛОГИКА ФИЛЬТРАЦИИ: Менеджер должен видеть только тех преподавателей, которые ведут группы в его направлении.
   - Шаг 1: Найди все группы направления менеджера: const myGroups = mockTeacherGroups.filter(g => g.direction === mockManager.direction);
   - Шаг 2: Собери уникальные ID преподавателей из этих групп: const myTeacherIds = [...new Set(myGroups.map(g => g.teacherId))];
   - Шаг 3: Отфильтруй массив преподавателей: const myTeachers = mockAllTeachers.filter(t => myTeacherIds.includes(t.id));

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции renderManagerTeachers() добавь логи:
   - console.log("Уникальные ID преподавателей направления:", myTeacherIds)
   - console.log("Найдено преподавателей:", myTeachers.length)
2. При отрисовке карточки преподавателя, для каждой группы собирай ее название (например, если у 't1' есть группы 101-ПР и 201-ПР, выведи их через запятую). Если групп нет (такое быть не должно по логике, но на всякий случай) — выведи "Нет групп".
3. Убедись, что преподаватель Иванова (t2), которая ведет группу 102-ДЗ (Дизайн), не отображается в списке, так как менеджер отвечает за Программирование.
4. Если массив myTeachers пуст, выведи заглушку: "В вашем направлении пока нет преподавателей".

ОГРАНИЧЕНИЯ
- Не делай пока управление студентами и отчёты.
- Не трогай другие экраны.
- Добавь переводы для новых текстов ("Преподаватели", "Добавить преподавателя", "Группы", "Нет групп", "Назначить группу") на 3 языка.
