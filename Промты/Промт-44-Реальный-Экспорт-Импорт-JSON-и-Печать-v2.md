ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- В панели Админа (раздел "Настройки") есть кнопка "Скачать резервную копию", которая сейчас вызывает alert("Скачивание JSON в разработке").
- В панели Студента (раздел "Зачётка") есть кнопка "Скачать PDF", которая сейчас вызывает alert("Экспорт в PDF в разработке").
- Все данные приложения хранятся в localStorage под ключами, начинающимися с unitest (например, uniteststudents, unitestalltests, unitest_results и т.д.).

ЗАДАЧА №44 — Реальный Экспорт/Импорт JSON и Печать Зачётки

ЧТО ДОЛЖНО БЫТЬ (ПОШАГОВО)

ШАГ 1. Реальный экспорт базы данных (Панель Админа)
1. Напиши функцию exportDatabase(), которая вызывается вместо alert при нажатии на кнопку "Скачать резервную копию".
2. Функция должна пройтись циклом по объекту localStorage и собрать все ключи, начинающиеся с unitest_. 
3. Сформируй объект: { uniteststudents: [...], unitestall_tests: [...], ... }.
4. Преобразуй объект в строку: const dataStr = JSON.stringify(backupData, null, 2);
5. Создай Blob с типом application/json, сгенерируй ссылку через URL.createObjectURL и программно нажми на нее (создай тег <a>, задай href и download="unitest_backup.json", вызови a.click()).

ШАГ 2. Реальный импорт базы данных (Панель Админа)
1. Добавь в раздел "Настройки" (рядом с кнопкой экспорта) кнопку "📤 Загрузить базу".
2. Создай скрытый <input type="file" id="import-file" accept=".json" style="display: none;">.
3. При клике на кнопку программно вызывай клик по этому инпуту (document.getElementById('import-file').click()).
4. Навесь обработчик onchange на инпут. При выборе файла используй FileReader, чтобы прочитать его содержимое.
5. Сделай JSON.parse полученной строки (оберни в try...catch, чтобы если файл битый, выскочил alert("Ошибка: неверный формат файла")).
6. Пройдись циклом по полученному объекту и запиши все данные обратно в localStorage (localStorage.setItem(key, JSON.stringify(value))).
7. После успешной записи выведи alert("База успешно восстановлена! Страница будет перезагружена.") и вызови location.reload().

ШАГ 3. Печать Зачётки (Панель Студента)
1. В функции renderStudentTranscript() замени alert на вызов window.print().
2. ДОБАВЬ CSS-ПРАВИЛА ДЛЯ ПЕЧАТИ:
   - В самом конце блока <style> добавь медиа-запрос @media print { ... }.
   - Внутри него скрой все лишние элементы: .sidebar { display: none !important; }, .header { display: none !important; }, .btn { display: none !important; }, .no-print { display: none !important; }.
   - Для основного контента задай: .main-content { margin: 0 !important; padding: 0 !important; width: 100% !important; }.
   - Измени цвета фона и текста принудительно, чтобы не тратить краску: body { background: #fff !important; color: #000 !important; }.
   - Убедись, что в печать попадает заголовок "Зачётка", имя студента и таблица с оценками.

ОГРАНИЧЕНИЯ
- ЗАПРЕЩЕНО использовать внешние библиотеки (jsPDF, html2canvas и т.д.). Только нативные средства браузера (Blob, FileReader, window.print).
- Не ломай текущую верстку экранов. Кнопки "Экспорт" и "Импорт" должны вписываться в общий дизайн.
- Убедись, что функции экспорта и импорта не вызывают ошибок, если в localStorage пусто.
