ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель менеджера: Дашборд, Группы, Преподаватели, Студенты, Тесты, Отчёты.
- Есть mockManager (direction: 'Программирование').
- Есть массив mockSchedule (из промтов №8 и №16). В нём есть поля: group, teacher, subject, day, time, room, type.
- В Sidebar менеджера есть пункт "Расписание".

ЗАДАЧА №22 — Панель менеджера: Расписание направления

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Расписание" в меню менеджера вызывается функция renderManagerSchedule().

2. Логика фильтрации (КРИТИЧЕСКИ ВАЖНО):
   - Менеджер должен видеть пары, которые относятся ТОЛЬКО к его направлению.
   - Шаг 1: Получи список групп направления менеджера (например, ['101-ПР', '201-ПР']).
   - Шаг 2: Отфильтруй mockSchedule, оставив только те пары, чья группа есть в этом списке.

3. Визуализация (Сетка):
   - Используй уже существующие CSS-классы для сетки расписания (как у студента в Промте №8), чтобы не писать стили с нуля.
   - Выведи дни недели и карточки пар.
   - В карточке пары для менеджера обязательно указывай: Время, Предмет, Преподавателя, Группу (например, "101-ПР") и Аудиторию.

4. Фильтр по дням (Опционально, если легко):
   - Можно добавить выпадающий список "Все дни" / "Понедельник" / "Вторник" и т.д. для удобства, но только если это не сломает верстку.
