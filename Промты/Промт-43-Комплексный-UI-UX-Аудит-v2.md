ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Проект функционально готов, проведен аудит безопасности и логики.
- В приложении есть таблицы, карточки, модальные окна, чат и выпадающие списки.
- Данные (имена, названия тестов, сообщения в чате) могут быть любой длины, а экраны пользователей — очень маленькими (от 320px).

ЗАДАЧА №43 — Комплексный UI/UX Аудит (Стресс-тест верстки)

ЧТО ДОЛЖНО БЫТЬ (ПОШАГОВО)

ШАГ 1. Защита от длинного текста (Text Overflow)
Если пользователь создаст тест с названием на 150 символов или отправит длинное сообщение в чат, верстка не должна ломаться (элементы не должны вылезать за края карточек).
1. Найди CSS-классы для карточек (тестов, пользователей, групп), ячеек таблиц и пузырей чата.
2. Добавь для них следующие CSS-свойства:
   - word-wrap: break-word; (перенос длинных слов).
   - overflow-wrap: break-word;
   - word-break: break-word;
   - hyphens: auto; (для расстановки переносов, если поддерживается).
3. Для заголовков карточек, которые не должны переноситься на вторую строку (например, название группы), используй обрезку:
   - white-space: nowrap;
   - overflow: hidden;
   - text-overflow: ellipsis;

ШАГ 2. Мобильная адаптация таблиц и модальных окон
1. Убедись, что все таблицы обернуты в <div class="table-responsive">. В CSS для этого класса пропиши: overflow-x: auto; -webkit-overflow-scrolling: touch; width: 100%;. Таблица должна скроллиться внутри этого дива, а не растягивать страницу.
2. Найди все модальные окна (создание теста, группы, пользователя, апелляции).
3. Добавь их внутреннему контейнеру (там, где лежит форма) стили:
   - max-height: 85vh; (чтобы окно не вылезало за пределы экрана телефона).
   - overflow-y: auto; (чтобы форма скроллилась внутри окна).
   - Убедись, что кнопки "Сохранить" и "Отмена" всегда доступны.
