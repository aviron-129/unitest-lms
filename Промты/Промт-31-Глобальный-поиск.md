ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

ЗАДАЧА №31 — Глобальный поиск

ЧТО ДОЛЖНО БЫТЬ
1. Кнопка поиска в шапке:
   - Рядом с колокольчиком добавь иконку лупы (🔍).
   - При клике на нее открывается выпадающая панель (как у уведомлений) с полем ввода "Поиск...".

2. Логика поиска (КРИТИЧЕСКИ ВАЖНО):
   - Поиск осуществляется при вводе текста (событие input).
   - Поиск нечувствителен к регистру (используй .toLowerCase()).
   - Правила поиска по ролям:
     • Если currentRole === 'student': ищем ТОЛЬКО по названиям тестов (mockTests).
     • Если currentRole === 'teacher': ищем по тестам (только своим) и по студентам (mockAllStudents).
     • Если currentRole === 'admin' или 'manager': ищем по тестам, студентам и преподавателям.

3. Отображение результатов:
   - Результаты группируются по категориям: "Тесты", "Пользователи" (для админа).
   - В результатах пиши: 
     • Для теста: Иконка документа + Название теста.
     • Для пользователя: Иконка юзера + ФИО + (Группа или Роль).
   - Если ничего не найдено, выведи "Ничего не найдено по запросу: [текст]".

4. Очистка:
   - При закрытии панели поиска (клик вне или на крестик) поле ввода должно очищаться.
