ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Проект полностью готов функционально. Есть переключатель тем (светлая/тёмная), который меняет класс на <body> (например, body.dark-theme) и использует CSS-переменные --bg, --text, --card-bg, --border-color и т.д.
- За время разработки мы добавили много компонентов (таблицы, модальные окна, чат, формы ввода). В некоторых из них могли остаться жестко заданные цвета (например, background: #fff; или color: #000;), которые ломают тёмную тему.

ЗАДАЧА №38 — Аудит и исправление тёмной темы

ЧТО ДОЛЖНО БЫТЬ
1. Аудит жестко заданных цветов:
   - Пройдись по всему CSS в файле. Найди правила, где используются явные цвета (#ffffff, #000000, white, black, #f5f5f5 и т.д.) для фонов, текста и границ. Замени их на соответствующие CSS-переменные (var(--card-bg), var(--text), var(--border-color)).
   
2. Стилизация инпутов и форм:
   - Убедись, что все теги <input>, <textarea>, <select> имеют фон var(--card-bg), текст var(--text) и рамку var(--border-color). 
   - Добавь правильный стиль для ::placeholder (он не должен быть черным на темном фоне).
   
3. Модальные окна и выпадающие меню:
   - Убедись, что модальные окна (создание группы, пользователя, апелляции) и выпадающие списки (уведомления, поиск, профиль) используют фон var(--card-bg), а текст — var(--text).
   
4. Таблицы и Чат:
   - В таблицах (Пользователи, Результаты, Отчёты) фон строк должен быть прозрачным, а при наведении (hover) — использовать полупрозрачный акцентный цвет, который виден и в светлой, и в тёмной теме.
   - В чате: сообщения от себя (справа) должны быть цвета акцента (с белым текстом), а сообщения от других (слева) — цвета var(--card-bg) с текстом var(--text).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. Напиши временную JS-функцию auditDarkTheme(), которая проверяет элементы на странице:
   - Функция должна искать элементы с инлайн-стилями (например, style="background: white"). Если находит — выводит console.warn("Найден жестко заданный цвет:", element).
   - Вызови эту функцию в конце renderAdminDashboard() и renderStudentProfile().
2. Добавь в консоль лог при переключении темы:
   - console.log("Тема изменена на:", currentTheme, "Все компоненты перекрашены")
3. ПРОВЕРКА КОНТРАСТНОСТИ: Убедись, что при включении тёмной темы текст на кнопках (особенно на второстепенных) не сливается с фоном.

ОГРАНИЧЕНИЯ
- НЕ МЕНЯЙ ЦВЕТА СВЕТЛОЙ ТЕМЫ. Она должна остаться точно такой же, какой была. 
- Не меняй структуру HTML, только классы и CSS-переменные.
- Если для какого-то элемента не хватает переменной, создай новую (например, --input-bg).

АДАПТИВНОСТЬ
