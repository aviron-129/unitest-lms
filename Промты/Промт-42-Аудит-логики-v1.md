ЧТО НУЖНО ПРОВЕРИТЬ И ИСПРАВИТЬ
1. Утечки таймеров:
   - Найди все места, где используется setInterval (например, таймер теста).
   - Проверь, что clearInterval вызывается АБСОЛЮТНО ВЕЗДЕ, где пользователь может прервать тест (нажатие "Завершить", переход на другую вкладку в Sidebar, выход из аккаунта, или обновление страницы через beforeunload).
   
2. Защита от пустых массивов (Undefined errors):
   - Найди все методы filter(), map(), find() и обращения к массивам по индексу (например, arr[0]).
   - Оберни их в проверки: if (arr && arr.length > 0) { ... }. Если массив пуст (например, админ удалил все группы), приложение не должно выдавать TypeError: Cannot read properties of undefined.
   
3. Сброс фильтров при переходе:
   - Если пользователь ввел запрос в глобальный поиск или выбрал фильтр по группе, а затем перешел на другую страницу (например, из "Пользователей" в "Группы"), фильтры должны сбрасываться, чтобы не показывать пустые экраны.
