ЗАДАЧА №30 — Глобальные уведомления в шапке

ЧТО ДОЛЖНО БЫТЬ
1. Единый компонент уведомлений:
   - При клике на колокольчик в шапке открывается выпадающая панель (dropdown).
   - Внутри: заголовок "Уведомления", кнопка "Отметить все как прочитанные" (если есть непрочитанные), и список уведомлений.

2. Разные уведомления для разных ролей:
   - Создай массив mockGlobalNotifications с полем targetRole (например, 'student', 'teacher', 'admin', 'manager').
   - Примеры:
     • Для студента: { id: 'n1', targetRole: 'student', title: 'Новый тест', text: 'Доступен тест по Математике', date: '10:00', read: false }
     • Для препода: { id: 'n2', targetRole: 'teacher', title: 'Студент сдал тест', text: 'Иванов И.И. сдал тест на 5', date: '11:30', read: false }
     • Для админа: { id: 'n3', targetRole: 'admin', title: 'Системное обновление', text: 'Платформа обновлена до v1.2', date: 'Вчера', read: false }
   - Показывай пользователю ТОЛЬКО те уведомления, где targetRole === currentRole. 
   - Сортируй по дате (новые сверху).

3. Логика прочитанного (localStorage):
   - При клике на "Отметить все как прочитанные" все текущие уведомления пользователя становятся прочитанными (красная точка на колокольчике исчезает, фон уведомлений меняется на прозрачный).
   - Сохраняй ID прочитанных уведомлений в localStorage (ключ unitestreadnotifications).
   - При перезагрузке страницы или повторном входе прочитанные уведомления не должны снова зажигать красную точку.

4. Привязка к роутеру:
   - При смене роли (например, выход и вход под другой ролью) колокольчик должен мгновенно перерисовываться и показывать уведомления новой роли.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции renderNotifications() (которая вызывается при клике на колокольчик):

   - Выведи лог: console.log("Уведомления для роли", currentRole, ":", filteredNotifications.length)
2. При нажатии на "Отметить все как прочитанные":

   - Проверь в localStorage, что массив прочитанных обновился.
3. ПРОВЕРКА КРАСНОЙ ТОЧКИ: Убедись, что если у пользователя нет непрочитанных уведомлений, красная точка на иконке колокольчика скрывается (display: none).
4. Если уведомлений нет вообще — выведи текст "Нет новых уведомлений".
