ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Цвета ролей: админ — фиолетовый, менеджер — синий, преподаватель — зеленый, студент — оранжевый.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готов файл index.html с шапкой, переключателями темы и языка.
- Готов Layout: при выборе роли открывается панель со Sidebar (боковое меню) и Main Content (рабочая область).
- В Sidebar есть пункты меню для каждой роли. При клике на пункт меняется заголовок в Main.
- Есть функция navigate(sectionName), которая обновляет Main.

ЗАДАЧА №3 — Панель студента: Карточка профиля и Дашборд

ЧТО ДОЛЖНО БЫТЬ
Сейчас мы работаем ТОЛЬКО с ролью 'student' и разделом 'Профиль' (или 'Дашборд').
Если текущая роль == 'student' и выбран пункт меню 'Профиль', в Main Content должно отрисоваться следующее:

1. Карточка профиля (Glassmorphism):
   - Крупный аватар (круг с инициалами или иконкой FontAwesome).
   - ФИО студента (например: Иванов Иван Иванович).
   - Бейдж категории (например, "⭐ Лучник" — цветной бейдж).
   - Сетка данных: Курс (1 курс), Направление (Программирование), Группа (101-ПР), Форма обучения (Очное).

2. Блок статистики (3 маленькие карточки в ряд):
   - "Доступно тестов": 4
   - "Пройдено": 2
   - "Средний балл": 4.5

ДАННЫЕ
- Создай глобальный объект mockStudent с полями: id, firstName, lastName, middleName, course, direction, group, form, category (например, 'Лучник').
- Создай объект studentStats с полями: available, passed, averageGrade.
- ВАЖНО: Чтобы не ломать другие панели, сделай функцию renderStudentProfile(), которая принимает эти объекты и возвращает HTML-строку.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции renderStudentProfile() перед возвратом HTML добавь проверку:
   - Если объект mockStudent пустой или undefined, выведи в консоль console.error("Данные студента не загружены!") и верни заглушку.
2. После отрисовки профиля добавь в консоль:
   - console.log("Профиль студента отрисован. Группа:", mockStudent.group)
3. Убедись, что если мы переключимся на роль 'admin', карточка студента НЕ отрисуется (вызывай renderStudentProfile только если role === 'student').

ОГРАНИЧЕНИЯ
- Не пиши пока логику тестов, кнопок "Начать тест" или расписания.
- Не удаляй существующую логику тем, языков и навигации.
- Соблюдай стиль из паспорта (скругления, стекло, акцентный цвет).
- Учти, что тексты в карточке профиля должны браться из объекта translations (добавь ключи для "Курс", "Направление", "Группа", "Форма обучения", "Доступно тестов" и т.д. на 3 языка).

АДАПТИВНОСТЬ
- На десктопе: карточка профиля сверху, под ней 3 карточки статистики в ряд.
- На мобильном: все элементы в столбик. Карточки статистики могут быть в 2 колонки или в 1 (если экран совсем узкий).
