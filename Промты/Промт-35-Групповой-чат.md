ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готовы все панели.
- Есть объекты mockStudent (группа: 101-ПР) и mockTeacher (ведет группы 101-ПР и 201-ПР).
- В Sidebar студента и преподавателя есть меню. Нам нужно добавить туда пункт "Чат" (с иконкой 💬).

ЗАДАЧА №35 — Групповой чат (Студент и Преподаватель)

ЧТО ДОЛЖНО БЫТЬ
1. Единая структура данных:
   - Создай массив mockMessages и синхронизируй его с localStorage (ключ unitest_messages).
   - Структура сообщения: { id: 'msg_' + Date.now(), groupName: '101-ПР', senderName: 'Иванов', senderRole: 'student', text: 'Привет!', time: '10:30' }.

2. Панель Студента (renderStudentChat()):
   - Интерфейс: Одно окно чата на весь экран.
   - Заголовок: "Чат группы [mockStudent.group]".
   - Окно с сообщениями (скроллится). 
   - Поле ввода и кнопка "Отправить" (или отправка по Enter).
   - Студент видит и отправляет сообщения ТОЛЬКО для своей группы.
   - Сообщения от самого студента выравниваются по правому краю (синий фон), от других — по левому (серый фон).

3. Панель Преподавателя (renderTeacherChat()):
   - Интерфейс: Две колонки.
     • Слева: Список групп преподавателя (из mockTeacherGroups). При клике на группу открывается чат.
     • Справа: Окно чата выбранной группы (аналогично студенту).
   - Преподаватель может переключаться между группами 101-ПР и 201-ПР.
   - Сообщения от препода выравниваются по правому краю, от студентов — по левому.

4. Логика отправки:
   - При отправке сообщения оно добавляется в mockMessages, сохраняется в localStorage и мгновенно отрисовывается на экране.
   - Поле ввода очищается.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции отправки сообщения (sendMessage()) проверь, чтобы пустые сообщения не отправлялись (используй .trim()). Добавь лог:
   - console.log("Отправлено сообщение в группу:", currentChatGroup, "Текст:", text)
2. В функции отрисовки сообщений (renderMessages()) отфильтруй сообщения:
   - const chatMessages = mockMessages.filter(m => m.groupName === currentChatGroup);
   - Добавь лог: console.log("Сообщений в чате", currentChatGroup, ":", chatMessages.length)
3. ГЛАВНАЯ ПРОВЕРКА: Зайди под студентом, отправь сообщение. Выйди, зайди под преподавателем, открой чат этой группы — сообщение студента должно быть там.
4. Окно чата должно автоматически прокручиваться вниз к последнему сообщению при открытии и при отправке (используй scrollTop = scrollHeight).

ОГРАНИЧЕНИЯ
- Никаких WebSockets или реального времени (только перерисовка после отправки или при открытии).
- Не трогай другие экраны.
- Добавь переводы для новых текстов ("Чат", "Чат группы", "Напишите сообщение...", "Отправить") на 3 языка.
