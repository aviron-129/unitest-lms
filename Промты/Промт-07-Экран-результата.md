ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Есть экран прохождения теста (test-taking), где студент отвечает на вопросы.
- По нажатию на "Завершить" сейчас просто выводится alert. Таймер останавливается, сохранение из localStorage удаляется.
- Есть массивы: mockQuestions (5 вопросов) и userAnswers (ответы студента).
- Есть список доступных тестов (mockTests) и экран профиля (renderStudentProfile).

ЗАДАЧА №7 — Экран результата (Круг, оценка, разбор)

ЧТО ДОЛЖНО БЫТЬ
1. Логика перехода:
   - При нажатии на кнопку "Завершить" на экране теста (вместо alert) должен вызываться подсчет результатов calcResult(), сохранение в localStorage и переход на экран 'test-result'.

2. Сохранение результата:
   - calcResult() должна считать правильные ответы, сравнивая userAnswers с mockQuestions[i].correct.
   - Рассчитать процент: (правильные / всего) * 100.
   - Высчитать оценку по шкале: >=90% → 5, >=75% → 4, >=60% → 3, иначе 2.
   - Сохранить результат в localStorage под ключом unitest_results (массив). Объект: { testId, testTitle, score, percent, grade, date, answers: userAnswers }.

3. Главный круг (SVG):
   - Круговая диаграмма (SVG circle с stroke-dasharray), которая показывает процент заполнения.
   - В центре: крупный текст с процентом (например "70%") и подпись "Ваш результат".
   - Под кругом: крупная оценка (5, 4, 3 или 2) с соответствующим цветом (5 — зеленый, 4 — синий, 3 — оранжевый, 2 — красный).
   - Анимация круга: плавное заполнение за 1 секунду при появлении экрана.

4. Статистика (карточки):
   - Правильных ответов: "X из Y".
   - Время прохождения (возьми текущее время или заглушку).
   - Дата прохождения.

5. Разбор ответов (Список вопросов):
   - Список всех вопросов (вопрос, варианты ответов).
   - Выбранный студентом ответ подсвечивается зеленым (если правильный) или красным (если неправильный).
   - Если ответ неверный, правильный вариант подсвечивается зеленым контуром/подчеркиванием.
   - Добавь иконки ✅ и ❌.
   - Кнопка-переключатель: "Показать только ошибки" (скрывает правильные ответы).

6. Действия (Кнопки внизу):
   - "Пройти заново" (возвращает на экран прохождения теста, обнуляет ответы).
   - "Вернуться к тестам" (возвращает на экран списка доступных тестов).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции calcResult() добавь:
   - console.log("Подсчет результатов. Правильных:", correctCount, "из", total, "Процент:", percent, "Оценка:", grade)
2. В функции renderResult() добавь:
   - console.log("Отрисовка экрана результатов. Переданный процент:", percent)
3. Убедись, что правильный ответ (индекс которого хранится в mockQuestions[i].correct) действительно совпадает с логикой проверки. 
4. Если userAnswers пустой (студент ничего не выбрал), процент должен быть 0, оценка 2.
