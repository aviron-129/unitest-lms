ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель Админа: Дашборд, Группы, Пользователи, Менеджеры, Отчёты.
- В Sidebar админа есть пункт "Настройки".
- Данные сохраняются в localStorage под разными ключами (uniteststudents, unitestteachers, unitestgroups, unitestresults и т.д.).

ЗАДАЧА №29 — Панель Администратора: Настройки и Журнал действий

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Настройки" вызывается функция renderAdminSettings().
   - Экран делится на две колонки (на десктопе) или два блока (на мобильном).

2. Блок 1: Журнал действий (Логи):
   - Выведи таблицу или список с последними действиями.
   - Колонки: Время, Пользователь (кто сделал), Действие.
   - Создай массив mockSystemLogs (5-6 записей). Пример:
     { time: '10:45', user: 'Смирнов А.А.', action: 'Создан тест "Математика. Контрольная №3"' }
     { time: '09:30', user: 'Админ', action: 'Добавлен новый студент: Иванов И.И.' }

3. Блок 2: Системные настройки:
   - Кнопка "📥 Скачать резервную копию" (при клике alert("Скачивание JSON в разработке")).
   - Опасная зона (красная рамка): Кнопка "⚠️ Сбросить базу данных".
   - При нажатии на "Сбросить":
     • Появляется confirm("Вы уверены? Все данные (тесты, пользователи, результаты) будут удалены!")
     • Если пользователь нажал "ОК", вызывается localStorage.clear(), выводится alert("База данных очищена. Страница будет перезагружена."), и страница перезагружается (location.reload()).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции renderAdminSettings() выведи в консоль:
   - console.log("Отрисовка настроек. Загружено логов:", mockSystemLogs.length)
2. При нажатии на кнопку сброса базы данных добавь логи:
   - console.log("Пользователь запросил сброс БД")
   - После очистки: console.log("localStorage очищен")
3. ГЛАВНАЯ ПРОВЕРКА: Убедись, что localStorage.clear() действительно удаляет сохраненные данные. После сброса и перезагрузки страницы система должна выглядеть так, как будто её только что открыли впервые (без созданных тестов и пользователей).

ОГРАНИЧЕНИЯ
- Не делай реального скачивания JSON (только alert).
- Не трогай другие панели.
- Добавь переводы для новых текстов ("Настройки", "Журнал действий", "Время", "Пользователь", "Действие", "Резервная копия", "Опасная зона", "Сбросить базу данных") на 3 языка.
