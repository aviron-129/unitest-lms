ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель Админа: Дашборд, Группы (создание/просмотр), Пользователи (таблица с поиском и фильтрацией).
- Есть массивы mockAllStudents и mockAllTeachers.
- В разделе "Пользователи" есть кнопка "➕ Добавить пользователя", которая сейчас вызывает alert.

ЗАДАЧА №26 — Панель Администратора: Добавление пользователя

ЧТО ДОЛЖНО БЫТЬ
1. Модальное окно "Добавить пользователя":
   - Вместо alert кнопка должна открывать модальное окно (или выезжающую панель).
   - Вверху поле: "Роль" (select: Студент / Преподаватель).
   - Поле "ФИО" (input type="text", обязательно).

2. Динамические поля (зависят от роли):
   - Если выбрана роль Студент, показываются поля:
     • "Группа" (select, заполняется из mockTeacherGroups).
     • "Курс" (number, 1-5).
     • "Форма обучения" (select: Очно/Заочно).
     • "Категория" (select: Лучник/Обычный).
   - Если выбрана роль Преподаватель, показывается поле:
     • "Предмет" (input type="text").
   - (При смене роли невидимые поля должны скрываться, а их значения сбрасываться).

3. Кнопки:
   - "Отмена" (закрывает окно).
   - "Сохранить".

4. Сохранение (Логика):
   - При нажатии "Сохранить" создается объект нового пользователя.
   - Для студента: { id: 's_' + Date.now(), name, group, course, form, category }.
   - Для препода: { id: 't_' + Date.now(), name, subject }.
   - Объект добавляется в соответствующий массив (mockAllStudents или mockAllTeachers).
   - Оба массива сохраняются в localStorage (ключи uniteststudents и unitestteachers).
   - Общий массив allUsers пересобирается, таблица перерисовывается, окно закрывается.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. При переключении роли в селекте добавь лог:
   - console.log("Выбрана роль:", selectedRole)
2. При сохранении добавь строгую валидацию:
   - Если ФИО пустое -> alert("Введите ФИО").
   - Если роль Студент и не выбрана группа -> alert("Выберите группу").
   - Если роль Преподаватель и пустой предмет -> alert("Введите предмет").
3. При успешном сохранении выведи:
   - console.log("Пользователь создан:", newUser)
   - console.log("Всего студентов теперь:", mockAllStudents.length) (или преподов).
4. ГЛАВНАЯ ПРОВЕРКА: Убедись, что новый пользователь появился в таблице и не исчез после F5 (благодаря localStorage).
