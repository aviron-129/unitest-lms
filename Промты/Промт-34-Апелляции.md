ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель преподавателя (Дашборд, Мои группы, Создание теста, Мои тесты, Результаты, Расписание, Объявления).
- Готова подача апелляций студентом (Промт 33). Апелляции сохраняются в localStorage под ключом unitest_appeals с полями: { id, testId, studentName, studentGroup, reason, date, status: 'pending' }.
- Результаты тестов хранятся в unitest_results.

ЗАДАЧА №34 — Апелляции (Часть 2: Рассмотрение преподавателем)

ЧТО ДОЛЖНО БЫТЬ
1. Новый пункт в Sidebar преподавателя:
   - Добавь в меню преподавателя пункт "Апелляции" (с иконкой ⚠️).
   - Если есть апелляции со статусом 'pending' для тестов этого преподавателя, рядом с пунктом меню должен гореть красный бейдж с числом (например, "2").

2. Рендер раздела (renderTeacherAppeals()):
   - При клике на "Апелляции" выводится список карточек.
   - Карточка содержит: 
     • ФИО студента и его группу.
     • Название теста (найди по testId в mockTests).
     • Причину (текст).
     • Статус (желтый бейдж "На рассмотрении", зеленый "Одобрено", красный "Отклонено").
   - Если статус 'pending', покажи кнопки: "✅ Одобрить" и "❌ Отклонить".
   - Если статус уже 'approved' или 'rejected', кнопки не показывай (только бейдж).

3. Логика одобрения/отклонения (КРИТИЧЕСКИ ВАЖНО):
   - Фильтрация: Преподаватель видит ТОЛЬКО те апелляции, которые относятся к тестам, созданным ИМ (связь: апелляция -> testId -> тест -> author === mockTeacher.name).
   - При клике "Одобрить":
     1. Статус апелляции меняется на 'approved'.
     2. В массиве unitest_results находится результат этого студента за этот тест, и его оценка (grade) меняется на 5 (и percent на 100).
     3. Сохраняются оба массива в localStorage.
     4. Список перерисовывается.
   - При клике "Отклонить":
     1. Статус меняется на 'rejected'.
     2. Оценка в результатах НЕ меняется.
     3. Сохраняется в localStorage.

4. ГЛАВНАЯ ПРОВЕРКА: Зайди под студентом после одобрения его апелляции, открой зачетку или результаты теста — оценка должна измениться на 5.
