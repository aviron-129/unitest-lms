ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готова панель Админа: Дашборд, Группы, Пользователи.
- В Промте №24 мы создали массив mockAllManagers (пока с одним менеджером Петровым).
- Есть массив mockTeacherGroups (содержит направления: 'Программирование', 'Дизайн').
- В Sidebar админа есть пункт "Менеджеры".

ЗАДАЧА №27 — Панель Администратора: Назначение менеджеров

ЧТО ДОЛЖНО БЫТЬ
1. Рендер раздела:
   - При клике на "Менеджеры" вызывается функция renderAdminManagers().

2. Таблица направлений (Десктоп) / Карточки (Мобильный):
   - Выведи список всех существующих направлений (получи их из mockTeacherGroups + можно добавить хардкодом пустые направления, если нужно).
   - Колонки таблицы: 
     • Направление (например, Программирование).
     • Текущий менеджер (ФИО или "Не назначен").
     • Кнопка "Назначить / Изменить".

3. Модальное окно назначения:
   - При клике на кнопку открывается окно.
   - Заголовок: "Назначить менеджера на [Название направления]".
   - Выпадающий список (select): все менеджеры из mockAllManagers + опция "Освободить должность" (снять менеджера).
   - Кнопки "Отмена" и "Сохранить".

4. Логика сохранения:
   - При сохранении обнови поле direction у выбранного менеджера в массиве mockAllManagers.
   - Если выбрано "Освободить", найди менеджера, который вел это направление, и сделай его direction = null.
   - Сохрани обновленный mockAllManagers в localStorage (ключ unitest_managers).
   - Перерисуй таблицу.

ДАННЫЕ
- Для начала работы функции добавь загрузку mockAllManagers из localStorage (если там пусто, используй дефолтный массив).
- Добавь в mockAllManagers еще одного менеджера (например, { id: 'm2', name: 'Сидорова А.А.', direction: null }), чтобы было из кого выбирать.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции renderAdminManagers() собери уникальные направления и добавь лог:
   - console.log("Направления для управления:", uniqueDirections)
2. При открытии модального окна проверь, что в списке менеджеров отображаются все (и Петров, и Сидорова). Добавь лог:
   - console.log("Открыто окно назначения для:", directionName)
3. При сохранении выведи в консоль:
   - console.log("Менеджер", manager.name, "назначен на", directionName)
   - console.log("Обновленный список менеджеров:", mockAllManagers)
4. ГЛАВНАЯ ПРОВЕРКА: Убедись, что один менеджер не может вести два направления одновременно (если его назначают на новое, у старого направления он должен исчезнуть). Если это сложно, то хотя бы проверь, что при назначении обновляется таблица и данные не пропадают после F5.

ОГРАНИЧЕНИЯ

- Не трогай другие панели.
