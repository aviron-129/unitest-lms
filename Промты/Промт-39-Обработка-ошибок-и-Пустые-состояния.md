ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Проект функционально готов. Есть роутер navigate(), который вызывает функции render... в зависимости от роли и выбранного пункта меню.
- Данные хранятся в массивах и localStorage.
- Сейчас, если массив пуст, приложение просто рендерит пустой экран без подсказок. Если в localStorage лежит битый JSON, скрипт может упасть с ошибкой SyntaxError.

ЗАДАЧА №39 — Обработка ошибок и Пустые состояния

ЧТО ДОЛЖНО БЫТЬ
1. Функция безопасного парсинга localStorage:
   - Создай функцию safeParse(key, fallback). Она должна пытаться сделать JSON.parse(localStorage.getItem(key)).
   - Если возникает ошибка (битый JSON) или данных нет, она должна вернуть fallback (дефолтный массив), очистить битый ключ и вывести console.warn("Ошибка чтения localStorage:", key).
   - Замени все прямые вызовы JSON.parse(localStorage.getItem(...)) на эту функцию.

2. Красивые пустые состояния (Empty States):
   - Создай функцию renderEmptyState(iconClass, title, description), которая возвращает HTML-блок с иконкой, заголовком и текстом.
   - Внедри эту функцию во все места, где выводятся списки:
     • Список тестов студента: "У вас пока нет доступных тестов".
     • Пользователи у админа: "Пользователи не найдены" (если пустой поиск или нет пользователей).
     • Мои группы у препода: "Вам еще не назначили группы".
     • Апелляции: "Нет активных апелляций".
     • Уведомления: "Нет новых уведомлений".

3. Глобальный перехватчик ошибок (Error Boundary):
   - Оберни вызовы всех функций render... внутри navigate() в блок try...catch.
   - Если функция рендера падает с ошибкой, catch должен перехватить ее, вывести в консоль console.error("Ошибка рендера:", error), а на экране показать заглушку: "Произошла ошибка при загрузке раздела. Попробуйте обновить страницу."
   - Добавь глобальный обработчик: window.addEventListener('error', function(e) { console.error("Глобальная ошибка:", e.message); });

4. Защита от пустых переменных:
   - Убедись, что функции типа renderStudentProfile() не ломаются, если mockStudent равен null или undefined. Добавь проверку: if (!mockStudent) return renderEmptyState('fa-user-slash', 'Ошибка', 'Данные студента не найдены');.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. Тест битого JSON: 
   - Добавь в консоль инструкцию для ручного теста: console.log("Чтобы проверить обработку ошибок, введите в консоли: localStorage.setItem('unitestalltests', 'битый_текст'); location.reload();")
2. В функции navigate() добавь логи:
   - console.log("Переход в раздел:", sectionName)
   - В блоке catch: console.error("Перехвачена ошибка при рендере раздела:", sectionName, error)
3. При вызове safeParse добавь лог: console.log("Безопасный парсинг ключа:", key, "Успешно:", isValid)

ОГРАНИЧЕНИЯ
- Не трогай бизнес-логику (создание, удаление). Только чтение и отображение.
- Не меняй стили карточек и таблиц. Блок "Пустое состояние" должен быть аккуратным, по центру экрана.
- Добавь переводы для новых текстов ("Произошла ошибка при загрузке раздела", "Данные не найдены" и т.д.) на 3 языка.

АДАПТИВНОСТЬ
- Блоки пустых состояний и ошибок должны быть отцентрированы (Flexbox) как по горизонтали, так и по вертикали в пределах Main Content.
