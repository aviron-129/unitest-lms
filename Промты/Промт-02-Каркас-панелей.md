ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Цвета ролей: админ — фиолетовый, менеджер — синий, преподаватель — зеленый, студент — оранжевый.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Файл index.html уже содержит: шапку с логотипом, переключатели темы и языка, экран входа с 4 карточками ролей.
- При клике на роль экран входа скрывается, показывается пустая заглушка с кнопкой "Выйти".
- Есть функции: initApp(), switchTheme(), changeLanguage(lang), selectRole(role), logout().

ЗАДАЧА №2 — Скелет внутренних панелей (Sidebar + Header + Main)

ЧТО ДОЛЖНО БЫТЬ
1. Общий Layout для всех панелей:
   - Экран заглушки (который появляется после выбора роли) нужно заменить на полноценный каркас:
     Слева — Sidebar (боковое меню), Справа — Header (верхняя панель) и Main Content (рабочая область).

2. Sidebar (Боковое меню):
   - Сверху: Аватар и Имя пользователя (mock-данные в зависимости от роли).
   - Ниже: список пунктов меню (навигация). Пункты зависят от роли!
     • Админ: Дашборд, Факультеты, Курсы, Группы, Пользователи, Менеджеры, Отчёты, Настройки.
     • Менеджер: Дашборд, Преподаватели, Группы, Студенты, Тесты, Отчёты, Расписание.
     • Преподаватель: Дашборд, Мои группы, Создать тест, Мои тесты, Результаты, Расписание.
     • Студент: Профиль, Доступные тесты, Расписание, Объявления, Зачётка.
   - У каждого пункта меню должна быть иконка FontAwesome.
   - При клике на пункт меню — он становится активным (меняется цвет фона или текста на акцентный).
   - Снизу Sidebar: кнопка "Выйти" (возвращает на экран входа).

3. Header (Верхняя панель внутри приложения):
   - Слева: Кнопка-бургер (для мобильных, скрыта на десктопе).
   - Справа: колокольчик уведомлений (с красной точкой) и переключатели языка/темы (дублируем их сюда, чтобы были под рукой, или оставляем в шапке).

4. Main Content (Рабочая область):
   - Пока просто белый/темный блок с заголовком: "Раздел: [Название выбранного пункта меню]".
   - При клике на разные пункты меню заголовок должен меняться.

ЛОГИКА И САМОПРОВЕРКА
- Создай объект menuConfig, где для каждой роли прописан массив её пунктов меню.
- Напиши функцию renderSidebar(role), которая генерирует HTML меню.
- Напиши функцию navigate(sectionName), которая обновляет заголовок в Main Content.
- САМОПРОВЕРКА В КОДЕ: Добавь console.log("Sidebar rendered for:", role) при отрисовке и console.log("Navigated to:", sectionName) при клике на меню.
- Убедись, что при клике на бургер (на мобильных) Sidebar выезжает слева поверх контента, а при клике на затемненный фон — закрывается.

ОГРАНИЧЕНИЯ
- Не пиши пока внутренний контент для каждого раздела (только заголовки-заглушки в Main).
- Обязательно сохраняй логику переключения тем и языков, которая была в промте №1. Не удаляй её.
- Все стили и код в том же файле index.html.

АДАПТИВНОСТЬ
- Десктоп: Sidebar шириной 260px слева, Header сверху, Main занимает оставшееся место.
- Планшет/Мобильный: Sidebar скрыт за экраном. При клике на бургер выезжает с анимацией (transform: translateX).
