ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Структура: курсы (1–5), направления (5–6), группы, форма обучения (очно/заочно).
Стек: HTML + CSS + JS (vanilla), без фреймворков и внешних библиотек (кроме шрифтов Google Fonts и иконок FontAwesome).
Данные: mock, хранятся в localStorage.
Языки: узбекский, русский, английский.
Темы: светлая и тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism (полупрозрачные карточки с размытием).
Адаптивность: mobile-first (брейкпоинты 480 / 768 / 1024).
Цвета ролей: админ — фиолетовый (#8b5cf6), менеджер — синий (#3b82f6), преподаватель — зеленый (#10b981), студент — оранжевый (#f59e0b).
Всё в одном HTML-файле (index.html), код должен быть подробно прокомментирован.

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
Это первый промт. Проект только начинается. Создай базовый файл index.html с нуля.

ЗАДАЧА №1 — Экран входа и каркас приложения

ЧТО ДОЛЖНО БЫТЬ
1. Шапка приложения (Header):
   - Слева: логотип/название "UniTest".
   - Справа: переключатель темы (иконка солнца/луны) и переключатель языка (выпадающий список или 3 кнопки: UZ / RU / EN).

2. Экран входа (Центральная часть):
   - Заголовок "Добро пожаловать" (или перевод).
   - 4 крупные карточки для выбора роли: Администратор, Менеджер, Преподаватель, Студент.
   - У каждой карточки должна быть иконка (FontAwesome), название роли и свой цвет акцента (из паспорта проекта).
   - Эффект при наведении: легкое увеличение карточки или изменение тени (hover-эффект).

3. Экран-заглушка для панелей (Router):
   - При клике на карточку роли экран входа скрывается.
   - Открывается пустой экран панели: в шапке пишется "Панель: [Название роли]", а в центре экрана — кнопка "Выйти" (возвращает обратно на экран входа).
   - Реальный контент панелей мы добавим в следующих промтах.

4. Темы и Языки (Сохранение в localStorage):
   - Реализуй объект translations с 3 языками. Переведи хотя бы заголовки: "Добро пожаловать", "Выберите роль", названия ролей и кнопку "Выйти".
   - Переключение языка должно мгновенно менять текст на экране и сохраняться в localStorage (ключ unitest_lang).
   - Переключение темы должно менять CSS-переменные (светлая/тёмная) и сохраняться в localStorage (ключ unitest_theme).

ДАННЫЕ
- Переменная currentRole (хранит выбранную роль: 'admin', 'manager', 'teacher', 'student').
- Настройки темы и языка при загрузке страницы должны читаться из localStorage.

ФОРМАТ
- Создай файл index.html.
- Внутри: <style> для CSS (используй CSS-переменные для тем: --bg, --text, --card-bg, --accent и т.д.), <body> с разметкой, <script> для логики.
- Используй шрифт Inter (подключи через Google Fonts) и FontAwesome для иконок (подключи через CDN).
- Напиши функции: initApp(), switchTheme(), changeLanguage(lang), selectRole(role), logout().

ОГРАНИЧЕНИЯ
- Никаких React/Vue и других фреймворков.
- Пока не делай внутреннее наполнение панелей (только пустую заглушку с кнопкой выхода).
- Весь код в одном файле.
- Обязательно комментируй логические блоки в JS и CSS.

АДАПТИВНОСТЬ
- На десктопе (1024px+): карточки ролей в один ряд (4 колонки).
- На планшете (768px): карточки в 2 колонки (сетка 2x2).
- На мобильном (480px): карточки в столбик (1 колонка).

ПОСЛЕ НАПИСАНИЯ
- Убедись, что переключение темы меняет цвета фона и текста на контрастные.
- Убедись, что при клике на роль открывается экран заглушки, а кнопка "Выйти" возвращает на главный экран.
