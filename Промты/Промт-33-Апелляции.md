ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Готов экран результатов теста (функция renderResult() из Промта №7). На нём есть кнопки "Пройти заново" и "Вернуться к тестам".
- Результаты сохраняются в localStorage (ключ unitest_results).
- Есть mockStudent (текущий студент).

ЗАДАЧА №33 — Апелляции (Часть 1: Подача студентом)

ЧТО ДОЛЖНО БЫТЬ
1. Кнопка на экране результатов:
   - В функции renderResult() найдите место рядом с кнопками "Пройти заново" и "Вернуться к тестам".
   - Добавьте кнопку "⚠️ Подать апелляцию".

2. Модальное окно подачи:
   - При клике на кнопку открывается модальное окно.
   - Заголовок: "Оспорить результат".
   - Текст-пояснение: "Опишите, почему вы не согласны с результатом".
   - Поле textarea для ввода причины (обязательное).
   - Кнопки: "Отмена" и "Отправить".

3. Логика сохранения:
   - При нажатии "Отправить" проверьте, не подавал ли студент уже апелляцию на этот тест.
   - Создайте объект апелляции: { id: 'app' + Date.now(), testId: currentTest.id, studentName: mockStudent.name, studentGroup: mockStudent.group, reason: text, date: 'текущаядата', status: 'pending' (На рассмотрении) }.
   - Добавьте его в массив mockAppeals и сохраните в localStorage (ключ unitest_appeals).
   - Закройте модальное окно и измените кнопку "Подать апелляцию" на бейдж "Апелляция на рассмотрении" (сделайте её неактивной).

4. Состояние при повторном заходе:
   - Если студент зайдет на экран результатов этого же теста позже (или обновит страницу), система должна проверить localStorage. Если апелляция уже есть, вместо кнопки должен отображаться бейдж "Апелляция на рассмотрении" (или "Апелляция отклонена/одобрена", в зависимости от статуса, который мы добавим позже).

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции открытия модального окна добавь лог: console.log("Открыто окно апелляции для теста:", currentTest.id)
2. В функции отправки апелляции добавь проверку:
   - Если причина пустая -> alert("Опишите причину апелляции").
   - Если апелляция уже существует в mockAppeals -> alert("Вы уже подали апелляцию на этот тест").
3. При успешном сохранении выведи:
   - console.log("Апелляция сохранена:", newAppeal)
   - console.log("Всего апелляций в базе:", mockAppeals.length)
4. ГЛАВНАЯ ПРОВЕРКА: После отправки апелляции перезагрузите страницу (F5) и зайдите в результаты этого же теста. Кнопки "Подать апелляцию" быть не должно, вместо неё — неактивный бейдж.
