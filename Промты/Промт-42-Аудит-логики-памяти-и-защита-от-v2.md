ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Проект полностью готов, проведен аудит безопасности (Промт 41).
- В приложении используются: таймеры (setInterval), динамическая перерисовка экранов (innerHTML), массивы данных и глобальные обработчики событий (document.addEventListener).
- Из-за динамической перерисовки могут возникать утечки памяти (дублирование событий) и падения при попытке прочитать несуществующие данные.

ЗАДАЧА №42 — Аудит логики, памяти и защита от падений

ЧТО ДОЛЖНО БЫТЬ (ПОШАГОВО)

ШАГ 1. Защита от утечек таймеров (Memory Leaks)
В тесте есть обратный отсчет. Если студент выйдет из теста, таймер может продолжать тикать в фоне, съедая память.
1. Вынеси ID таймера в глобальную переменную: let activeTestTimerId = null;.
2. При запуске теста (startTest) и вызове setInterval сохраняй ID в activeTestTimerId.
3. Найди функцию navigate(sectionName), функцию logout() и функцию завершения теста.
4. В САМОМ НАЧАЛЕ каждой из этих функций добавь проверку:

   if (activeTestTimerId) {
       clearInterval(activeTestTimerId);
       activeTestTimerId = null;
