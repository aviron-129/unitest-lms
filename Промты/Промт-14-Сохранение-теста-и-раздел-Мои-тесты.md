ПАСПОРТ ПРОЕКТА
UniTest — LMS-платформа для университета.
Роли: админ, менеджер, преподаватель, студент.
Стек: HTML + CSS + JS (vanilla), без фреймворков. Всё в одном HTML-файле (index.html).
Данные: mock, localStorage.
Языки: uz, ru, en. Темы: светлая/тёмная.
Стиль: минимализм, скругления 16px, акцент #6366f1, шрифт Inter, glassmorphism.
Адаптивность: mobile-first (480 / 768 / 1024).

КОНТЕКСТ ПРЕДЫДУЩИХ ПРОМТОВ
- Есть глобальная переменная currentTestDraft (черновик теста), которая заполняется на Шагах 1 и 2.
- Есть массив mockTests (тесты, которые видят студенты).
- В Sidebar преподавателя есть пункт "Мои тесты".
- Сейчас кнопка "Завершить создание" просто выводит alert.

ЗАДАЧА №14 — Сохранение теста и раздел "Мои тесты"

ЧТО ДОЛЖНО БЫТЬ
1. Сохранение теста (интеграция):
   - При нажатии на "Завершить создание" в конструкторе вопросов вызывается функция saveTestToDB().
   - Она берет currentTestDraft, добавляет ему уникальный id (например, 'test_' + Date.now()), статус status: 'active' и имя создателя author: mockTeacher.name.
   - Тест добавляется в глобальный массив mockTests (который используют студенты).
   - Массив mockTests сохраняется в localStorage под ключом unitestalltests (чтобы не пропадал при обновлении страницы).
   - После сохранения очищается currentTestDraft и происходит переход на раздел "Мои тесты".

2. Раздел "Мои тесты" (renderTeacherTests()):
   - При клике на "Мои тесты" в Sidebar, отрисовывается список.
   - Выводятся ТОЛЬКО тесты, созданные этим преподавателем (test.author === mockTeacher.name).
   - Карточка теста содержит:
     • Название и предмет.
     • Для каких групп и курсов он назначен.
     • Количество вопросов и время.
     • Статус (зеленый бейдж "Активен").
     • Кнопка "Удалить" (🗑️), которая удаляет тест из mockTests, обновляет localStorage и перерисовывает список.

САМОПРОВЕРКА (ОБЯЗАТЕЛЬНО)
1. В функции saveTestToDB() добавь логи:
   - console.log("Сохранение теста:", currentTestDraft.title)
   - console.log("Всего тестов в базе после сохранения:", mockTests.length)
2. В функции renderTeacherTests() отфильтруй тесты:
   - const myTests = mockTests.filter(t => t.author === mockTeacher.name);
   - console.log("Мои тесты. Найдено:", myTests.length)
3. Если у преподавателя нет тестов, выведи заглушку: "Вы еще не создали ни одного теста" и кнопку "Создать первый тест".
4. ГЛАВНАЯ ПРОВЕРКА: Убедись, что при сохранении теста, его targetCourse, targetGroup и targetForm в точности соответствуют тому, что выбрал преподаватель, чтобы студент смог его увидеть.

ОГРАНИЧЕНИЯ
- Не трогай панель студента (логика фильтрации тестов у студента уже написана и должна просто подхватить новый тест).
- Не делай редактирование теста (только создание и удаление).
- Добавь переводы для новых текстов ("Мои тесты", "Создать первый тест", "Активен", "Удалить") на 3 языка.

АДАПТИВНОСТЬ

- На мобильном в одну колонку.
